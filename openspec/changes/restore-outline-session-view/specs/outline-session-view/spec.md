## Purpose

Сохранять открытый Outline и его ширину по вкладкам и проектам, используя настоящие символы текущего файла и прежнюю нативную навигацию.

## ADDED Requirements

### Requirement: IDE-PANEL-26 Открытость и ширина Outline в сессии
Редактор SHALL восстанавливать открытость и ширину Outline по сохранённым вкладкам и проектам, сохраняя прежнее native follow-поведение символов для восстановленного файла и code cursor.
Платформы: все.
Проверка: tests/e2e/session-outline-view.test.lua, tests/e2e/outline-focus.test.lua.

#### Scenario: Quit и несколько вкладок
- **GIVEN** Outline открыт с разной шириной в двух code tabpages
- **WHEN** редактор штатно закрывается, запускается и восстанавливает сессию
- **THEN** Outline виден в тех же вкладках с прежней шириной при том же UI
- **AND** native provider возвращает символы соответствующего файла, фокус остаётся в коде

#### Scenario: A → B → A и меньший терминал
- **GIVEN** проекты имеют разные Outline views, в одной вкладке он скрыт
- **WHEN** пользователь переключается между проектами и возвращается
- **THEN** каждый проект возвращает свой вид, скрытая панель остаётся скрытой
- **AND** при меньшем UI ширина адаптируется без потери окна кода

#### Scenario: Прежние сессии и остальные панели
- **GIVEN** сессия содержит Files/Logs и не содержит новых данных Outline
- **WHEN** она восстанавливается
- **THEN** прежние Files/Logs и legacy fallback работают как прежде
- **AND** восстановление Outline не запускает тесты, debug или terminal process
