# Design

## Context

Есть BufferLine, Telescope, safe-close в ide.empty и независимые история/
порядок/предикаты в keymaps.lua. Общие панели уже покрыты E2E. Закрытие сейчас
запрашивает решение после замены окон; последнее закрытие подавляет bdelete error.

## Goals / Non-Goals

**Goals:** единая файловая модель, сохранность данных/окон, понятный reopen,
настоящие E2E на Windows/Ubuntu и воспроизводимая команда Mac.

**Non-Goals:** новые Neovim tabpage/workspace команды, управление вкладками
WezTerm, перенос сессии между процессами, Save As dialog, LSP матрица и GUI.
Save без имени сообщает о необходимости имени и сохраняет буфер открытым.

## Decisions

- ide.buffers хранит предикат, порядок/посещения, окно назначения и закрытые
  пути. ide.empty остаётся совместимым facade; старые команды/aliases сохраняются.
- Обычные listed буферы (bt='') проходят в файловый цикл; tool/terminal — нет.
  Unloaded не исключаются. Порядок берётся из реального BufferLine с добавлением
  ещё не отрисованных буферов; закрытие выбирает доступный соседний файл.
- Решение dirty-close — native confirm Save/Discard/Cancel, default Cancel,
  перед мутациями. Write выполняется в контексте буфера; при ошибке WARN и выход.
  После решения все окна удаляемого файла заменяются, split/панели не закрываются.
- Reopen хранит существующий путь/курсор ограниченным стеком, только после
  успешного явного закрытия; не перехватывает удаления при rename Neo-tree.
- Telescope использует штатный entry_maker с файловым фильтром, запуск из окна
  кода. BufferLine получает тот же custom_filter. Plugin-функции не патчатся.
- E2E — настоящий UI/confirm и файлы на диске. Для modal ожиданий используются
  fast get_mode/nvim_input; Lua RPC за confirm не вызывается. Действия теста не
  подменяют confirm, write или plugin callbacks.

## Risks / Trade-offs

- Alpha — placeholder редактора; reopen должен использовать его окно, не split.
- Buffer id может смениться после bdelete/reopen; контракт — путь/текст/курсор.
- Native confirm имеет реальные клавиши s/d/c; проверки не подтверждают GUI
  доставку модифицированных клавиш, Mac остаётся отдельным запуском владельца.

## Уточнения по воспроизведениям

- Auto-save пишет по BufLeave немедленно и по debounce после InsertLeave.
  Поэтому до confirm нужно не только не менять окна, но и отменить уже
  запланированную запись. Штатный cancel_deferred_save получил User
  ForgeBufferClose; condition блокирует только закрываемый буфер до решения.
  Plugin-функции/таймеры не заменяются; после Cancel обычный autosave доступен.
- Write выполняется как silent write (ошибка не подавляется), иначе сообщение
  записи после confirm могло открыть лишний hit-enter.
- Telescope entry_maker получает явный bufnr_width: его штатная фабрика
  форматирования должна знать ширину до запуска builtin picker.
- Native confirm имеет режим r? при blocking=false. Транспорт E2E проверяет
  этот режим fast API и не отправляет Lua RPC за modal, editor.lua защищён.
- Из terminal используется существующий F7 (его выход в normal — noremap).
  Обычный Ctrl-\ перехватывает ToggleTerm; это отдельный вопрос терминальных
  привязок, здесь их конфигурация не меняется. Курсор в тесте ожидается после
  завершения nvim_input, а не считывается сразу из очереди.
