## Purpose

Объединяет файловые вкладки, цикл и picker и сохраняет данные/раскладку при
закрытии, отмене и восстановлении последнего закрытого файла.

## ADDED Requirements

### Requirement: IDE-BUF-1 Общая модель файловых вкладок

Редактор SHALL использовать один критерий файлового буфера для BufferLine,
next/prev и picker: listed обычный буфер, включая ещё не загруженные файлы
и обычный unnamed буфер; tool/terminal MUST исключаться. Существующие
Space b n/p, Tab/S-Tab, Alt-h/l и Space b b/f b SHALL сохраняться. Переключение
или выбор из панели SHALL направлять файл в код, сохраняя tool-буфер и окна.
Цикл SHALL соответствовать порядку файловых вкладок и проходить границу списка.
Файловые действия MUST NOT создавать/закрывать Neovim tabpages или вкладки WezTerm.

Платформы: все
Проверка: tests/e2e/buffers.test.lua (IDE-BUF-1)

#### Scenario: обычные, unloaded и terminal буферы
- **WHEN** пользователь переключает файлы, включая badd/unloaded и readonly,
  при открытом настоящем terminal
- **THEN** файл загружается в код, terminal не становится файловой вкладкой
- **AND** порядок/окна и количество tabpages сохраняются

#### Scenario: picker из панели
- **WHEN** пользователь вызывает Space b b/f b из дерева и подтверждает файл
- **THEN** picker содержит файловые буферы, выбранный файл открыт в коде
- **AND** дерево/terminal и их буферы сохранены

### Requirement: IDE-BUF-2 Закрытие сохраняет данные и раскладку

Редактор SHALL принимать Save/Discard/Cancel для изменённого буфера до замены
окон/удаления буфера. Cancel или ошибка записи MUST сохранять исходный файл,
текст, modified, курсор и раскладку. Save SHALL записывать файл до закрытия;
Discard SHALL закрывать без записи. Space b d и закрытие файлового контекста
через F4/Alt-w SHALL использовать одно поведение. Другие файлы и панели MUST
сохраняться. После последнего файла SHALL быть alpha в существующем окне.

Платформы: все
Проверка: tests/e2e/buffers.test.lua (IDE-BUF-2)

#### Scenario: Cancel для последнего и непоследнего файла
- **WHEN** пользователь отменяет закрытие изменённого файла
- **THEN** до и после решения окна показывают те же буферы, текст не скрыт

#### Scenario: Save и Discard
- **WHEN** пользователь выбирает Save либо Discard
- **THEN** файл закрывается, запись на диске соответствует выбору
- **AND** соседний файл занимает прежнее окно без схлопывания split/панелей

#### Scenario: ошибка записи
- **WHEN** Save не может записать буфер, например у unnamed нет имени
- **THEN** редактор сообщает о неудаче, буфер остаётся открытым и modified

### Requirement: IDE-BUF-3 Возврат закрытого файла

Space b r SHALL открывать последний явно закрытый существующий файл в окне
кода и восстанавливать курсор с учётом текущей длины файла. Закрытие с Cancel
MUST NOT менять историю. Возврат из alpha или панели MUST сохранять окна.
История SHALL содержать пути, не копии отброшенного текста; unnamed/отсутствующий
файл MUST NOT открываться как фантомный восстановленный файл.

Платформы: все
Проверка: tests/e2e/buffers.test.lua (IDE-BUF-3)

#### Scenario: последний файл и повторное открытие
- **WHEN** последний сохранённый файл закрыт, затем нажато Space b r
- **THEN** alpha заменяется файлом в том же окне и курсор восстановлен
- **AND** остальные панели и tabpages не изменились
