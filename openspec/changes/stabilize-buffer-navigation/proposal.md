# Proposal

## Why

Следующий пункт IDE_ROADMAP — управление открытыми файлами/вкладками с E2E.
Сейчас буферы выбираются несколькими предикатами в keymaps.lua и ide/empty.lua;
цикл и BufferLine считают любой listed буфер вкладкой, а закрытие использует
другой критерий. close_buffer_safe меняет окна до confirm, при последнем файле
сначала показывает alpha и подавляет ошибку bdelete. Это создаёт риск скрыть
несохранённый текст и потерять фокус. Требования: IDE-BUF-1/2/3.

## What Changes

- Общая модель файловых буферов для цикла, picker и BufferLine; обычные
  unloaded буферы сохраняются, tool/terminal исключаются из файлового цикла.
- Закрытие с Save/Discard/Cancel до изменения окон; отказ/ошибка записи
  сохраняет текст, выбранный файл и раскладку. Последний файл показывает alpha.
- Space b r возвращает последний закрытый существующий файл с курсором.
- Старые Space b n/p/d, Tab/S-Tab, Alt-h/l/w, F4, Space b b/f b сохраняются;
  вход из панели направляет файл в код и не заменяет tool-буфер.
- Настоящие editor E2E и Windows/Ubuntu регресс, команда владельцу для Mac.

## Capabilities

### New Capabilities

- `buffer-navigation`: файловые вкладки, выбор, безопасное закрытие и возврат.

### Modified Capabilities

Нет. Контракты существующих панелей/WezTerm сохраняются.

## Impact

ide.buffers, совместимый facade ide.empty, keymaps, BufferLine/Telescope,
E2E/реестр, инструкции, FIXLOG и хронология. Общий код для Windows/macOS/Ubuntu,
без изменения версий зависимостей и без автоматических установок.
