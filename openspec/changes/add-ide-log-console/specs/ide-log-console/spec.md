# Spec Delta

## Purpose

Общая консоль помогает пользователю из одного места найти причину сбоя IDE,
отсутствующий инструмент и подробный источник диагностики без мыши.

## ADDED Requirements

### Requirement: IDE-LOG-1 Общая консоль и единое управление

IDE SHALL открывать общую консоль логов по Space w i и :ForgeLogs.
Консоль MUST поддерживать общие focus/code/hide/help/zoom и сохранять
выбранный источник, фильтры и сообщения при закрытии/повторном открытии.
Поздний возврат фокуса от ранее отказанного Debug MUST сохранять явно
выбранную пользователем рабочую панель.

Платформы: все.
Проверка: tests/e2e/ide-logs.test.lua; physical WezTerm — отдельно.

#### Scenario: Открыть и вернуть консоль
- **WHEN** пользователь открывает консоль, смотрит помощь, меняет фокус и размер, скрывает её и открывает снова
- **THEN** сообщения/источник/фильтр сохранены, код остаётся доступен, работающие jobs продолжаются

#### Scenario: Поздний фокус после отказанного Debug
- **GIVEN** F5 не нашёл Node и возврат фокуса ещё ожидает выполнения
- **WHEN** пользователь уже выбрал Logs или другую рабочую панель
- **THEN** поздний callback сохраняет новый выбор и не начинает отладку

### Requirement: IDE-LOG-2 Причины, missing tools и источники подробностей

Консоль SHALL показывать время, уровень, источник и текст сообщений IDE,
включая ранние уведомления и ошибки после завершения всплывающего сообщения.
Она SHALL давать доступ к штатным Neovim/LSP/DAP/format/tests/Git/tasks/setup
журналам, существующим output buffers и общей проверке готовности.
Отсутствующий/отключённый источник MUST явно отличаться от доступного пустого.
Для известных missing-tool сообщений MUST сохраняться конкретное действие
подготовки, а для остальных ошибок — исходная причина и путь к подробностям.

Платформы: все.
Проверка: tests/e2e/ide-logs.test.lua.

#### Scenario: Настоящий missing tool
- **WHEN** реальный запуск отладки не находит необходимый инструмент
- **THEN** пользователь находит в консоли предупреждение с причиной и командой подготовки
- **AND** исправление настройки позволяет повторить действие без перезапуска IDE

#### Scenario: Подробный журнал подсистемы
- **WHEN** выбран существующий native журнал или output buffer
- **THEN** консоль показывает его содержимое/путь и границу прочитанного хвоста
- **AND** отсутствующий журнал отображается как недоступный, а не как отсутствие ошибок

#### Scenario: Раннее сообщение и native ошибка
- **WHEN** ошибка возникает до готовности plugin UI или через native механизм сообщений
- **THEN** она доступна в общей консоли после открытия редактора
- **AND** обычный механизм отображения сообщений продолжает работать

#### Scenario: Большая строка и Unicode на границе хвоста
- **WHEN** native журнал или история сообщений длиннее доступного хвоста
- **THEN** доступный хвост сохранён, даже если он целиком внутри одной длинной строки
- **AND** начало UTF-8 корректно, усечение обозначено, источник не назван пустым

### Requirement: IDE-LOG-3 Поиск, фильтры и отчёт

Консоль SHALL позволять с клавиатуры выбирать источник, фильтровать уровень
и текст, сбрасывать фильтр, читать подробности и копировать отчёт.
Пустой результат фильтра MUST отличаться от отсутствующей диагностики.

Платформы: все.
Проверка: tests/e2e/ide-logs.test.lua.

#### Scenario: Найти нужную ошибку
- **WHEN** пользователь выбирает источник, уровень и текстовый фильтр
- **THEN** остаются совпадающие сообщения, а сброс возвращает исходный список
- **AND** копирование содержит отображённую диагностику и источник без изменения файлов проекта

### Requirement: IDE-LOG-4 Пассивная ограниченная история

Просмотр консоли SHALL оставаться пассивным: не устанавливать tools,
не запускать debug/tests/tasks и не менять уровни native logging.
Консоль SHALL сохранять ограниченную историю между запусками, обозначать
сессии/ограничения хранения и сбои записи. Она MUST не собирать environment,
notification data или значения debug variables и удалять распознаваемые
credentials из своих записей/отчёта. Native журналы остаются у их владельцев.

Платформы: все.
Проверка: tests/e2e/ide-logs.test.lua и native restart test; Mac отдельно.

#### Scenario: Перезапуск
- **WHEN** редактор закрыт и снова запущен с тем же state directory
- **THEN** сохранённые сообщения доступны с прежней границей сессии
- **AND** повреждённая строка истории не мешает открыть консоль и обозначена

#### Scenario: Ограничения и отказ хранения
- **WHEN** поток сообщений превышает лимит или state directory недоступен для записи
- **THEN** размер сохраняемой истории ограничен, а консоль сообщает о потере старых записей или persistence failure
- **AND** редактор и штатные уведомления продолжают работать

#### Scenario: Пассивность и credentials
- **WHEN** пользователь открывает/фильтрует/обновляет консоль и копирует отчёт
- **THEN** новые jobs/установки не запускаются и native журналы не изменяются
- **AND** поля environment/data/debug variables не экспортируются, распознаваемые credentials скрыты
