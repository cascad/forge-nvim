## MODIFIED Requirements

### Requirement: WT-SCROLL-7 Copy mode: выделение и копирование `y`
В copy mode `v` и Space SHALL начинать посимвольное выделение от курсора, `V` — построчное, Ctrl+`v` — прямоугольное, а `y` MUST копировать непустое выделение в системный буфер по правилу WT-CLIP-1 и выключать copy mode.
Платформы: все
История: FIXLOG §42
Проверка: tests/wezterm/clipboard.test.lua (сценарии «Посимвольное выделение и y», «y без выделения стирает буфер»); вручную на windows и macos (сценарий «y без выделения стирает буфер», результат — в записи FIXLOG)

Повторное нажатие клавиши того же вида выделения снимает выделение, клавиша другого вида меняет вид. Выделенное совпадение поиска (WT-SCROLL-8) считается посимвольным выделением от своего начала: `v` его снимает, `V` делает построчным. `o` / `O` переносят курсор на другой конец выделения (по вертикали / по горизонтали для блока). `y` без выделения буфер не трогает и только выключает copy mode, как и с выделением. Ctrl+Shift+C, Ctrl+Insert и Cmd+C в copy mode копируют выделение, не выключая его (WT-CLIP-4, WT-CLIP-5). Ctrl+`v` здесь — прямоугольное выделение, а не вставка. Ctrl+C — выход без копирования.

#### Scenario: Посимвольное выделение и y
- **GIVEN** панель в copy mode
- **WHEN** нажато `v`, курсор сдвинут `w` `w`, нажато `y`
- **THEN** в буфере текст от начальной позиции до курсора
- **AND** copy mode выключен, вид в конце истории

#### Scenario: Построчное выделение
- **GIVEN** панель в copy mode
- **WHEN** нажато Shift+`v`, затем `j` `j`, затем `y`
- **THEN** в буфере три строки целиком

#### Scenario: Прямоугольное выделение
- **GIVEN** в выводе таблица, панель в copy mode
- **WHEN** нажато Ctrl+`v`, курсором очерчен столбец через несколько строк, нажато `y`
- **THEN** в буфере только этот столбец, построчно

#### Scenario: Повторное v снимает выделение
- **GIVEN** в copy mode начато выделение `v`
- **WHEN** нажато `v` ещё раз
- **THEN** выделения нет, курсор на месте

#### Scenario: v на выделенном совпадении
- **GIVEN** в copy mode `n` выделило совпадение поиска
- **WHEN** нажато `v`
- **THEN** выделение снято, курсор остаётся в конце совпадения

#### Scenario: y без выделения стирает буфер
- **GIVEN** в буфере текст «A», панель в copy mode, выделения нет (например, сразу после Ctrl+Shift+X во вкладке, где ещё не искали)
- **WHEN** нажато `y`
- **THEN** буфер не стирается: в нём по-прежнему «A»
- **AND** copy mode выключен, вид в конце истории

#### Scenario: Копирование без выхода
- **GIVEN** панель в copy mode, выделен фрагмент
- **WHEN** нажата Ctrl+Shift+C
- **THEN** в буфере текст выделения
- **AND** copy mode остаётся включённым
