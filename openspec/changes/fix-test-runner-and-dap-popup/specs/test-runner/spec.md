## Purpose

Запуск и отладка выбранного теста из редактора с понятным результатом,
без зависимости обычного запуска от наличия сессии отладчика.

## ADDED Requirements

### Requirement: IDE-TEST-1 Обычный ближайший тест

Редактор SHALL запускать только выбранный тест под курсором обычным test
runner, без создания DAP-сессии, показывать результат и вывод. Пути с
пробелами MUST работать одинаково на целевых ОС. Запуск файла запускает
тесты файла, не подменяя семантику nearest.

Платформы: все
Проверка: tests/e2e/test-runner.test.lua (IDE-TEST-1)

#### Scenario: два Go-теста и путь с пробелами
- **GIVEN** проект с успешным тестом и соседним намеренно падающим тестом
- **WHEN** курсор в успешном тесте и пользователь нажимает Space T t
- **THEN** запускается успешный тест, соседний не исполняется
- **AND** вывод виден в Test Output, DAP-сессии и No active session float нет

#### Scenario: падающий тест и запуск файла
- **WHEN** пользователь запускает падающий тест, затем файл через Space T f
- **THEN** видны реальные результаты и текст ошибки без блокирующего overlay
- **AND** после скрытия Output можно продолжить редактирование файла

### Requirement: IDE-TEST-2 Отладка ближайшего теста

Редактор SHALL запускать выбранный Go-тест через реальный Delve отдельно
от обычного test runner, останавливаться на breakpoint и сохранять вывод.

Платформы: все
Проверка: tests/e2e/test-runner.test.lua (IDE-TEST-2)

#### Scenario: debug nearest
- **WHEN** пользователь ставит breakpoint и нажимает Space T d в Go-тесте
- **THEN** создаётся DAP-сессия и тест останавливается на breakpoint
- **AND** соседний тест не выполняется; после continue итог теста доступен в REPL
- **AND** статус skipped адаптера для DAP не объявляется успешным test-runner результатом
