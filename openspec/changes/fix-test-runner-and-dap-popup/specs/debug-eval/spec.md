## Purpose

Вычисление выражений во время паузы отладчика с предсказуемым закрытием
временного окна и безопасным поведением при отсутствии подходящей сессии.

## ADDED Requirements

### Requirement: IDE-DAP-3 Контекст eval и закрываемое окно

Eval SHALL открывать окно значения только при paused-сессии с frame.
Без сессии или во время исполнения MUST показываться краткое сообщение
без пустого No active session float. Esc и q SHALL закрывать временное
DAP-окно без удаления файла, продолжения или остановки debug-сессии.

Платформы: все
Проверка: tests/e2e/test-runner.test.lua (IDE-DAP-3)

#### Scenario: eval без сессии
- **WHEN** пользователь нажимает Space d e без DAP-сессии
- **THEN** пустое окно не открывается, код остаётся доступен

#### Scenario: оставшийся DAP float
- **GIVEN** DAP expression float уже открыт
- **WHEN** пользователь нажимает Esc или q в нём
- **THEN** окно закрывается и фокус возвращается в код
- **AND** Esc из кода также закрывает оставшийся DAP float

#### Scenario: значение на паузе
- **GIVEN** реальный Go-тест остановлен на breakpoint
- **WHEN** пользователь вычисляет локальную переменную и закрывает окно
- **THEN** видно реальное значение; после закрытия та же сессия остаётся paused
