## ADDED Requirements

### Requirement: IDE-BUF-4 Удалённый на диске файл сохраняется в памяти

Редактор SHALL при обнаружении удаления загруженного файлового буфера сохранять его имя, текст и modified, показывать одно неблокирующее предупреждение и удерживать autosave до успешной явной записи. Смена фокуса, повторная проверка файла и закрытие Git-панели MUST оставаться доступными без E211/ожидания ввода. Правило SHALL действовать одинаково для удаления worktree и отдельного файла на всех ОС.
Платформы: все
Проверка: tests/e2e/deleted-files.test.lua, tests/e2e/git-workflow.test.lua (IDE-GIT-3)

#### Scenario: Удаление открытого worktree
- **GIVEN** открыты загруженные файлы linked worktree, включая скрытые буферы
- **WHEN** пользователь удаляет чистый worktree через Git-панель
- **THEN** каталог удалён, файлы основного worktree сохранены, редактор принимает ввод
- **AND** все оставшиеся буферы и текст сохранены без E211 и блокирующего prompt
- **AND** существующая защита dirty worktree и отказ от force сохраняются

#### Scenario: Удаление отдельного файла с изменениями
- **GIVEN** файл загружен и содержит изменения в памяти, включая ожидающую autosave запись
- **WHEN** удаление обнаружено до выполнения autosave
- **THEN** текст и modified сохранены, ожидающая запись отменена, файл не создаётся автоматически
- **AND** последующий ввод/смена фокуса не восстанавливают файл через autosave
- **AND** повторная проверка/выбор того же буфера не дублируют предупреждение

#### Scenario: Явная запись и восстановление
- **GIVEN** удалённый файл остался открытым
- **WHEN** пользователь успешно выполняет write или Save As
- **THEN** данные записаны по явно выбранному пути, autosave снова разрешён
- **AND** новая независимая потеря файла снова вызывает одно предупреждение

#### Scenario: Внешнее изменение существующего файла
- **GIVEN** файл остаётся на диске
- **WHEN** меняется его содержимое извне
- **THEN** немодифицированный буфер обновляется штатным autoread
- **AND** при конфликте с изменённым буфером сохраняется стандартный выбор Neovim, данные не перезаписываются молча
