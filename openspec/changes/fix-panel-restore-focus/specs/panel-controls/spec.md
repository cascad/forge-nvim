## Purpose

Восстановление рабочих панелей сохраняет фокус кода и более поздний явный
выбор пользователя, включая завершение отложенного открытия дерева файлов.

## ADDED Requirements

### Requirement: IDE-PANEL-23 Фокус после общего восстановления панелей

Общее восстановление панелей SHALL оставлять фокус в коде после завершения
отложенного открытия Files. Это SHALL действовать и для открытия Files по
умолчанию без сохранённого набора. Более поздний явный выбор фокуса общими
командами IDE SHALL сохраняться после готовности дерева; явный выбор Files
SHALL отменять автоматический возврат. Данные, состав панелей, процессы и
остальные вкладки SHALL сохраняться.

Платформы: все
Проверка: tests/e2e/panel-restore-focus.test.lua; panel-transitions и соседние UI E2E.

#### Scenario: Восстановление набора
- **GIVEN** штатно открыты Files и Quickfix
- **WHEN** пользователь скрывает и восстанавливает общий набор
- **THEN** обе панели восстановлены, после готовности дерева фокус в коде

#### Scenario: Открытие по умолчанию
- **WHEN** пользователь включает панели без сохранённого набора
- **THEN** Files открывается, фокус остаётся в коде после его готовности

#### Scenario: Последующий явный выбор
- **GIVEN** дерево ещё открывается после восстановления
- **WHEN** пользователь выбирает Logs или Files общей командой фокуса IDE
- **THEN** выбранная панель остаётся в фокусе после завершения открытия

#### Scenario: Штатный фокус после готовности
- **WHEN** после восстановления пользователь вызывает штатный фокус Files
- **THEN** дерево доступно и получает фокус обычным способом
