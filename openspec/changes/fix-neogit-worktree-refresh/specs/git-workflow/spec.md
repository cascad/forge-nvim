## Purpose

Общий путь работы с Git в терминальной IDE: переключение worktree во время незавершённых обновлений сохраняет доступность интерфейса и согласованность выбранного корня, истории и графа.

## ADDED Requirements

### Requirement: IDE-GIT-6 Быстрый visit и согласованная история
Редактор SHALL поддерживать посещение другого worktree во время незавершённого обновления Git status без async error/hit-enter и после обновления показывать Head, историю и граф выбранной рабочей папки.
Платформы: все
Проверка: tests/e2e/worktree-refresh.test.lua

#### Scenario: Переход при незавершённой истории
- **GIVEN** два worktree с разными HEAD и история первого ещё загружается
- **WHEN** пользователь посещает второй worktree и завершается прежняя загрузка
- **THEN** интерфейс остаётся доступным без ожидания прежней загрузки
- **AND** cwd и готовый status относятся ко второму worktree, поздний callback не возвращает пользователя в первый
- **AND** commit и его линия графа соответствуют одной истории
- **AND** содержимое файлов, HEAD и index обоих worktree сохраняются

#### Scenario: Серия посещений и повторное открытие
- **GIVEN** два worktree с отличающимися последними commit
- **WHEN** пользователь быстро посещает их несколько раз и открывает историю последнего выбранного worktree
- **THEN** Head/recent/log показывают выбранную ветку и её commit
- **AND** повторное посещение и обновление работают без traceback и блокирующего prompt

#### Scenario: Полный tab и боковая панель
- **GIVEN** Git открыт через полный tab либо боковую панель
- **WHEN** пользователь быстро меняет worktree
- **THEN** оба маршрута сохраняют согласованную историю и существующие клавиши управления
