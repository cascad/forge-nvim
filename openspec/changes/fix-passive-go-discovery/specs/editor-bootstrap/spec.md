# Spec Delta

## Purpose

Подготовленный редактор отделяет пассивное отображение состояния инструментов
от явной подготовки, диагностики и запуска пользовательских программ.

## ADDED Requirements

### Requirement: IDE-BOOT-4 Пассивная Go metadata и поздний выбор Delve

nvim_forge SHALL отображать Go metadata без запуска поиска Delve или Go version
из открытия файла и отрисовки statusline. Версия SHALL запрашиваться только
явным GoVersion/GoToolchain, а актуальный путь Delve — при debug или явном
DapGoDlvInfo. Настройка GOTOOLCHAIN и готовый language backend MUST сохранять
свои обычные правила для реальной работы пользователя.

Платформы: все
Проверка: tests/e2e/go-passive.test.lua (IDE-BOOT-4)

#### Scenario: открытие файла с отсутствующим project SDK
- **GIVEN** плагины и Go SDK подготовлены, модуль требует отсутствующий toolchain
- **WHEN** пользователь открывает Go-файл и statusline перерисовывается
- **THEN** metadata label и поиск debug adapter не запускают Go/Delve процессы
- **AND** не вызывают toolchain download и его hit-enter сообщения
- **AND** label показывает выбранный режим/toolchain либо default, не выдуманную установленную версию

#### Scenario: явный запрос версии
- **GIVEN** версия ещё не запрошена и текущий Go доступен
- **WHEN** пользователь вызывает GoVersion
- **THEN** реальный Go version запускается асинхронно один раз на запрос
- **AND** завершившийся результат показывается вместе с контекстом запроса и обновляет текущую label
- **AND** чтение версии и перерисовка не создают дополнительных запросов

#### Scenario: результат устаревшего контекста
- **GIVEN** версия запрошена для прежних cwd/toolchain/PATH/GOENV
- **WHEN** контекст сменился до доставки результата
- **THEN** прежний результат не заменяет label текущего контекста
- **AND** явное уведомление не приписывает прежнюю версию новому контексту

#### Scenario: явное переключение toolchain
- **GIVEN** пользователь работает с Go-файлом
- **WHEN** вызывается GoToolchain с выбранным режимом
- **THEN** выбранное окружение применяется и gopls перезапускается как прежде
- **AND** явное асинхронное уточнение версии остаётся доступным без фоновых дублей

#### Scenario: Delve стал доступен после открытия файла
- **GIVEN** Go-файл уже открыт, затем появился реальный Delve и настроен его override
- **WHEN** пользователь запускает debug
- **THEN** используется актуальный override без перезапуска редактора
- **AND** настоящая сессия достигает breakpoint и показывает stdout
- **AND** обычный выбор из GOBIN/GOPATH/PATH/Mason с приоритетом версий сохраняется
