## ADDED Requirements

### Requirement: IDE-BOOT-1 Пассивный запуск подготовленной сборки

Подготовленный nvim_forge SHALL запускаться и выполнять базовые действия
редактора без автоматической установки LSP/DAP/форматтеров и Treesitter-парсеров.
Установка этих инструментов MUST запускаться явным действием пользователя
или отдельным setup-скриптом. Уже установленные LSP включаются как раньше.

Платформы: все
Проверка: tests/e2e/editor.test.lua (IDE-BOOT-1)

#### Scenario: пустое хранилище инструментов после подготовки плагинов
- **GIVEN** плагины по lazy-lock.json подготовлены, HOME/data/state изолированы
- **WHEN** запущен настоящий nvim_forge, пройден VeryLazy и открыты обычные файлы
- **THEN** нет автоматических curl/wget для установки инструментов/парсеров
- **AND** нет события MasonToolsStartingInstall

#### Scenario: явная подготовка доступна
- **GIVEN** редактор запущен с подготовленными плагинами
- **WHEN** завершена их загрузка
- **THEN** доступны команды ForgeTreesitterInstall и MasonToolsInstall/Sync
- **AND** обычное редактирование не вызывает эти команды автоматически

### Requirement: IDE-BOOT-2 Контекст отсутствующего языкового инструмента

Редактор SHALL сообщать об отсутствующем gopls при работе с Go-файлом,
а не при первом открытии файла другого языка или обычного текста.

Платформы: все
Проверка: tests/e2e/editor.test.lua (IDE-BOOT-2)

#### Scenario: обычный текст без Go SDK
- **GIVEN** gopls отсутствует в PATH
- **WHEN** пользователь открывает и редактирует .txt, ищет файлы и переключает панели
- **THEN** уведомление об отсутствующем gopls не показывается
- **AND** работа не останавливается на hit-enter из-за этого уведомления

#### Scenario: отсутствует Go LSP для Go-файла
- **GIVEN** gopls отсутствует в PATH
- **WHEN** пользователь впервые открывает Go-файл
- **THEN** редактор объясняет отсутствие Go LSP и способ установки
