## Context

66 плагинов подготовлены по lazy-lock.json. Реальный запуск в изолированном
HOME всё равно начал загрузку парсеров. Поздние ошибки видны только при живом
процессе; проверки декларативных opts этого не обнаруживали.

## Goals / Non-Goals

Goals: единая для Windows/macOS/Linux политика — установка инструментов
явно; обычная работа не вызывает установку LSP/DAP/парсеров.

Non-Goals: менять shell-профили Mac без фактов, отключать пользовательский
Go toolchain глобально, менять первый bootstrap lazy.nvim, менять версии
или способы установки инструментов, выдавать новый core e2e за GUI-проверку.

## Decisions

Оставляем декларативный каталог mason-tool-installer и ручные команды.
run_on_start=false, дублирующий ensure у mason-lspconfig пуст. Одного пустого
списка недостаточно: setup моста всегда обновляет registry. Мост загружается
только явными LspInstall/LspUninstall, интеграции-переводчики имён отключены
у mason-tool-installer (каталог уже содержит package names).
Доступные серверы включает нативный vim.lsp.enable после настройки; Mason bin
добавляется в PATH зависимостью mason.nvim. Отсутствующий gopls сообщает о себе
только на FileType go; .txt больше не вызывает длинное предупреждение/hit-enter.
Treesitter main не вызывает install вне ForgeTreesitterInstall; legacy
не выполняет ensure/auto_install. Явные setup-скрипты продолжают вызывать
существующие команды, дополнительный слой пакетного менеджера не нужен.

## Risks / Trade-offs

Новая машина требует явного setup; отсутствие инструментов остаётся
видимым через Mason/health. E2E фиксирует запуск curl/wget и событие Mason,
но не проверяет успешную установку пакетов без сети или полноценную работу
LSP/DAP. Установленные пакеты не копируются в private профиль core e2e;
проверка доступности gopls зависит от PATH, в Ubuntu он отсутствует.
macOS ждёт прогона.

## Migration Plan

После обновления установить инструменты явно через setup/команды при
необходимости. Уже установленные инструменты не удаляются и не обновляются.
