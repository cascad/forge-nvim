# Spec Delta

## Purpose

Восстановление рабочей сессии возвращает пользователя к редактированию сохранённых файлов. Дерево доступно слева, а служебные окна и повторные действия не перехватывают клавиатурный фокус.

## ADDED Requirements

### Requirement: IDE-PANEL-15 Фокус кода после восстановления сессии

Редактор SHALL после успешного восстановления сессии с файлами открывать Explorer слева и оставлять фокус в обычном окне кода. Способ входа в проект SHALL NOT менять эту политику; сохранённые файлы, cursor positions и tabpages сохраняются. Восстановление старых window-local winfix опций SHALL NOT оставлять файл в области панели. Если именованный файл сохранён только в списке буферов, восстановление SHALL позволять продолжить его редактирование без выбора панели как редактора.

Платформы: все.
История: FIXLOG §167.
Проверка: tests/e2e/project-session.test.lua, tests/e2e/session-legacy.test.lua; Ubuntu/macOS отдельные gates.

#### Scenario: Restore с клавиатуры
- **GIVEN** после обычного выхода новый редактор открыт в том же проекте
- **WHEN** пользователь нажимает Space qs
- **THEN** восстановлены файлы/tabpages/cursors и открыт Explorer
- **AND** фокус находится в обычном окне кода

#### Scenario: Возврат в проект
- **GIVEN** у проекта A сохранена сессия с файлами
- **WHEN** пользователь переходит A→B→A штатным переключением проектов
- **THEN** новый backend восстанавливает сессию A и Explorer
- **AND** фокус находится в коде, а буферов B в редакторе нет

#### Scenario: Старые winfix опции
- **GIVEN** native session сохраняет file window с winfixwidth
- **WHEN** сессия восстановлена
- **THEN** файл доступен в обычном окне без panel marker/winfix
- **AND** Explorer не перехватывает фокус

#### Scenario: Скрытый сохранённый файл
- **GIVEN** session содержит именованный listed file, а сохранённое видимое окно служебное
- **WHEN** сессия восстановлена при входе в проект
- **THEN** фокус возвращается в обычное окно с сохранённым файлом
- **AND** Explorer остаётся доступен слева

#### Scenario: Новый проект без сессии
- **GIVEN** проект B ещё не имеет сохранённой сессии
- **WHEN** пользователь переходит в B
- **THEN** открыт Explorer и сохранён прежний вход в новый проект
- **AND** файлы проекта A не переносятся в B
