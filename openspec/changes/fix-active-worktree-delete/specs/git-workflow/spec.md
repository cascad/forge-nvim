## Purpose

Работа с Git из терминальной IDE сохраняет доступность редактора и файлов при удалении текущей дополнительной рабочей папки, с одинаковыми подтверждениями на целевых системах.

## ADDED Requirements

### Requirement: IDE-GIT-7 Удаление текущего linked worktree
Редактор SHALL удалять чистый текущий linked worktree после обычного подтверждения, переходя в основной worktree до удаления; отдельное принудительное подтверждение для чистой папки не требуется.
Платформы: все
Проверка: tests/e2e/active-worktree.test.lua

#### Scenario: Чистый текущий worktree
- **GIVEN** Git status открыт в дополнительном worktree с путём, содержащим пробелы, и открыты его файлы
- **WHEN** пользователь выбирает удаление этого worktree и подтверждает его
- **THEN** каталог и запись worktree удалены, cwd и обновлённый status относятся к основной папке
- **AND** нет лишнего force prompt, traceback или блокирующей ошибки
- **AND** текст открытых файлов сохранён; редактор, status и следующий worktree доступны

#### Scenario: Отказ от принудительного удаления
- **GIVEN** текущий дополнительный worktree содержит изменённый файл
- **WHEN** пользователь подтверждает обычное удаление, но отказывается от force
- **THEN** каталог, Git worktree и изменённое содержимое сохраняются
- **AND** после явного сохранения изменений в commit обычное удаление успешно

#### Scenario: Подготовка временного исправления
- **GIVEN** установлена закреплённая версия плагина с известным исходным содержимым
- **WHEN** пользователь явно готовит исправление либо повторяет подготовку
- **THEN** используется проверенное исправленное содержимое без повторного изменения уже подготовленного файла
- **AND** обычная работа редактора не переписывает исходники плагина
- **AND** при неизвестной версии или содержимом подготовка завершается с понятной ошибкой и сохраняет исходный файл
