# Проверка IDE-154 / IDE-FILE-10

Исходная сборка `075c4ca` воспроизводит синхронный `uv.fs_copyfile` из `c`.
`windows-source.log` фиксирует реальный вызов на временном проекте. После
исправления используется тот же observable путь через клавиши Neo-tree.

| Проверка | Windows | Ubuntu |
| --- | ---: | ---: |
| Copy, delete и защита изменённых буферов | 11 PASS | 11 PASS |
| Files и штатные файловые операции | 7 PASS | 7 PASS |
| Отказы ОС и отзывчивость при удалении | 6 PASS | 6 PASS |
| Подготовка companion LF/CRLF и отказ на неизвестном файле | 3 PASS | 3 PASS |
| Всего уникальных | 27 PASS | 27 PASS |

Главный пакет на каждой ОС запущен один раз. В двух сценариях начальный
диалог `c`, перенесённый в асинхронный callback, открывался с курсором перед
последней буквой. Прежний начальный диалог снова открывается в обработчике
клавиши, а введённое имя проверяется асинхронно. Повторены эти два сценария
и затронутая проверка каталога. Backport-фильтр выполнен с ID `IDE-FILE-5`.

Сценарий удержанного копирования прошёл на обеих ОС. Он проверяет сохранение
файла из кода до завершения запроса, событие успеха после завершения, появление
копии в дереве и сохранение фокуса. При занятой цели оригинальные данные и
содержимое цели сохраняются. `EEXIST` от libuv виден в логах. За проходы с
опубликованными ссылками на артефакты проверено по 21 завершению редактора.

Логи и сводка находятся в `.tests/async-copy`. Версии зависимостей, SDK,
WezTerm и базовые спеки сохранены. У Neo-tree изменён один действующий
companion, предыдущий SHA принят для обновления. macOS остаётся для ручной
приёмки. Дефекты создания и остальных операций выделены в дорожной карте.
