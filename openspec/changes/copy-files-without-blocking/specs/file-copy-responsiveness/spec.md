## ADDED Requirements

### Requirement: IDE-FILE-10 Копирование в Files сохраняет отзывчивость

Копирование файла или каталога через `c` или `y` → `p` SHALL оставлять
редактор доступным для навигации, редактирования и сохранения файлов,
пока файловая система выполняет операцию. Занятая цель MUST сохраняться.
Событие успешного добавления SHALL приходить после успешного копирования.
При отказе ОС причина и путь MUST оставаться доступными в логах IDE.
Пока копирование выполняется, fride SHALL показывать его статус без смены
фокуса. Статус обновляется при успехе и снимается при ошибке.

Платформы: все.
История: FIXLOG §309 и §310.
Проверка: tests/e2e/file-copy-delete.test.lua.

#### Scenario: Копирование с ожидающим запросом

- **GIVEN** Files запустил настоящий запрос копирования
- **WHEN** запрос ещё ожидает завершения
- **THEN** пользователь переключается в код и сохраняет другой файл
- **AND** индикатор показывает имя копируемого файла и обновляется при успехе
- **AND** после завершения копия видна в раскрытой папке и фокус остаётся в коде.

#### Scenario: Назначение заняли после выбора имени

- **WHEN** цель появляется после проверки имени, пока запрос копирования ожидает выполнения
- **THEN** содержимое цели и источника сохраняется
- **AND** IDE сообщает об отказе и не публикует успешное добавление.
- **AND** индикатор ожидания исчезает без сообщения об успехе.
