## Purpose

Возвращать рабочий вид общей консоли логов при повторном открытии проекта и переключении между репозиториями, сохраняя существующую историю сообщений.

## ADDED Requirements

### Requirement: IDE-LOG-5 Вид Logs в проектной сессии
Редактор SHALL восстанавливать видимость, высоту и прокрутку Logs по сохранённым вкладкам, а также общий выбранный источник, уровень и текстовый фильтр этой консоли для проекта.
Платформы: все.
Проверка: tests/e2e/session-logs-view.test.lua, tests/e2e/ide-logs.test.lua.

#### Scenario: Quit и повторный вход
- **GIVEN** Logs открыт в сохранённой вкладке с выбранным источником, фильтрами и прокруткой
- **WHEN** пользователь штатно закрывает редактор, запускает снова и восстанавливает сессию
- **THEN** Logs открыт в той же вкладке с прежним видом и высотой при том же размере UI
- **AND** скрытый Logs другой вкладки остаётся скрытым, фокус возвращается в код
- **AND** при меньшем UI высота адаптируется и код остаётся доступен

#### Scenario: Проекты A → B → A
- **GIVEN** у двух проектов разные виды и фильтры Logs
- **WHEN** пользователь переключается в другой проект и возвращается
- **THEN** каждый проект возвращает свой вид консоли и настоящую сохранённую историю
- **AND** обновление сообщений сохраняет просматриваемую позицию в доступных границах

#### Scenario: Прежние данные и процессы
- **GIVEN** подходящая сессия содержит только прежний снимок Files либо не содержит снимка
- **WHEN** пользователь восстанавливает проект
- **THEN** прежние Files и безопасный fallback продолжают работать
- **AND** отсутствие источника или строки логов не ломает восстановление, позиция ограничивается доступными строками
- **AND** восстановление представления не запускает завершённые процессы или инструменты
