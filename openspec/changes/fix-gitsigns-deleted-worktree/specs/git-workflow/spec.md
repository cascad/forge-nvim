## Purpose

Фоновые Git-проверки терминальной IDE сохраняют доступность редактора, открытый текст и правильный корень операций при удалении рабочей папки между асинхронными запросами.

## ADDED Requirements

### Requirement: IDE-GIT-8 Незавершённые signs и исчезнувший worktree
Редактор SHALL оставаться доступным без async traceback/hit-enter, если worktree исчез во время начального получения Git signs; текст открытых файлов сохраняется, дальнейшие Git-операции используют выбранный репозиторий.
Платформы: все
Проверка: tests/e2e/gitsigns-worktree.test.lua

#### Scenario: Удаление между двумя фоновыми запросами
- **GIVEN** открыт файл linked worktree и его начальный Git diff ещё загружается
- **WHEN** пользователь удаляет worktree, а прежний запрос завершается после удаления
- **THEN** следующие запросы к исчезнувшему пути не блокируют редактор исключением запуска процесса
- **AND** текст сохраняется, последующее открытие файла main и stage/unstage его hunk работают

#### Scenario: Отказ удалить изменённый worktree
- **GIVEN** initial signs linked worktree ещё загружаются и его файл изменён
- **WHEN** пользователь отказывается от force удаления
- **THEN** каталог, текст, main HEAD и main index сохраняются
- **AND** signs завершают загрузку, stage hunk меняет index именно linked worktree

#### Scenario: Явная подготовка одного плагина
- **GIVEN** доступны декларации исправлений нескольких закреплённых плагинов
- **WHEN** пользователь явно готовит один выбранный плагин либо проверяет/отменяет его исправление
- **THEN** операция затрагивает только выбранный плагин и проверяет его исходный/итоговый hash
- **AND** неизвестное имя/содержимое не изменяет файлы, обычная загрузка только проверяет подготовку
