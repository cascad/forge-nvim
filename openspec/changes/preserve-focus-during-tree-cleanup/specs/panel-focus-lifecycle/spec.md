# Spec Delta

## Purpose

Сохраняет выбранное пользователем окно, когда отложенная операция старой панели
завершается после смены раскладки и требуется убрать лишнее окно.

## ADDED Requirements

### Requirement: IDE-PANEL-10 — фокус при фоновом закрытии дерева

Если после выбора Outline поздняя операция дерева создаёт лишнее окно,
редактор SHALL убрать это окно и сохранить Outline в левом слоте.
Cleanup MUST NOT переводить фокус из выбранной панели в код.
Если позднее окно временно получило фокус, редактор SHALL вернуть предыдущее
действительное окно. Если пользователь уже явно выбрал окно кода, cleanup
SHALL сохранить именно это окно. Недействительное окно MUST NOT вызывать ошибку.

#### Scenario: Первое асинхронное открытие Outline
- **WHEN** пользователь переключает дерево на Outline, а отложенная операция дерева завершается позже
- **THEN** виден только Outline, фокус остаётся в нём после появления символов

#### Scenario: Позднее окно поверх Outline
- **WHEN** фокус в Outline и поздний producer дерева создаёт лишнее окно
- **THEN** после очистки фокус возвращается в прежнее окно Outline, а код не меняется

#### Scenario: Явный переход в код
- **WHEN** перед завершением поздней операции пользователь выбрал одно из окон кода
- **THEN** после очистки фокус остаётся в этом окне и не возвращается принудительно в Outline
