# Spec Delta

## ADDED Requirements

### Requirement: IDE-PANEL-29 Корень файловой системы как выбранная папка

IDE SHALL принимать существующий корень файловой системы как выбранную
папку: '/' на POSIX, корень диска на Windows. Файлы внутри выбранного корня
SHALL участвовать в сохранении и восстановлении проектной сессии так же,
как файлы обычного каталога. История: FIXLOG §231. Платформы: все.
Проверка: tests/e2e/project-session.test.lua (IDE-PANEL-29).

#### Scenario: Выбор корня и возврат к его сессии

- **GIVEN** пользователь работает в обычной папке
- **WHEN** выбирает filesystem root, открывает файл внутри него, переходит
  в другую папку и возвращается
- **THEN** корень остаётся корректным cwd, открытый файл восстанавливается
- **AND** переключение выполняется обычным перезапуском редактора

#### Scenario: Обычный проект

- **WHEN** пользователь переключает два обычных проекта A→B→A
- **THEN** сохраняются файлы, вкладки и изменённый перед переключением текст
