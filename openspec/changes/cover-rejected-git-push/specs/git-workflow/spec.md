## Purpose

Клавиатурный Git-сценарий терминальной IDE сохраняет локальные и удалённые
коммиты при отказе push и позволяет прочитать причину и повторить операцию.

## ADDED Requirements

### Requirement: IDE-GIT-10 Ошибка push и повтор
Редактор SHALL показывать отказ push и предоставлять его подробности через
клавиатуру, сохраняя локальные изменения/commit и remote историю. После
устранения причины пользователь SHALL иметь возможность повторить push
в той же сессии. Обычный push SHALL NOT перезаписывать remote историю без
явно выбранного принудительного действия пользователя.
Платформы: все
Проверка: tests/e2e/git-errors.test.lua (частные локальные bare remotes)

#### Scenario: Remote содержит независимый commit
- **GIVEN** локальная и удалённая ветки имеют независимые коммиты
- **WHEN** пользователь выполняет обычный push и отказывается от предложения force
- **THEN** отказ и причина rejected доступны в интерфейсе с клавиатуры
- **AND** local HEAD, index, файлы и remote HEAD сохраняются
- **AND** после явного согласования историй повторный обычный push проходит в той же сессии

#### Scenario: Недоступный remote
- **GIVEN** локальный commit готов, origin указывает на отсутствующий локальный репозиторий
- **WHEN** пользователь выполняет push и читает подробности ошибки
- **THEN** commit и рабочие файлы сохраняются, причина недоступности remote видима
- **AND** пользователь может закрыть вывод и вернуться в код
- **AND** после исправления origin повторный push отправляет исходный commit
