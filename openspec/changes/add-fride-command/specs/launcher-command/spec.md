## Purpose

Постоянная команда fride для независимого комплекта и checkout, с одинаковыми аргументами запуска на целевых ОС и сохранением существующего софта пользователя.

## ADDED Requirements

### Requirement: IDE-BOOT-12 Команда fride

Комплект SHALL предоставлять fride и полное имя forge-nvim, сохраняя прежний локальный forge. Команда MUST запускать тот же изолированный профиль и native SDK, передавать argv/cwd/stdin/TTY/exit code и восстанавливать окружение вызывающего PowerShell. Checkout SHALL предоставлять fride через прежние launch helpers без нового resolver.
Платформы: все.
Проверка: tests/install-isolation.test.py.

#### Scenario: Основное и совместимые имена
- **WHEN** пользователь запускает fride, forge-nvim или прежний forge из bin комплекта
- **THEN** запускается собственный native Neovim с теми же config/data/state/cache
- **AND** аргументы с пробелами/Unicode, cwd, stdin/TTY и exit code сохраняются

#### Scenario: Запуск checkout
- **WHEN** пользователь запускает fride из checkout
- **THEN** используется прежний поддерживаемый launch helper и профиль nvim_forge
- **AND** штатные nvim_forge.cmd/nvim_forge.sh продолжают работать

#### Scenario: Явная регистрация
- **GIVEN** пользователь явно указал отдельный каталог команды
- **WHEN** установка успешно подготовлена
- **THEN** там создаётся принадлежащий Forge launcher fride и receipt владения
- **AND** PATH/registry/profile shell не изменяются
- **AND** отсутствующие родители выбранного каталога создаются автоматически

#### Scenario: Portable и повтор
- **WHEN** каталог регистрации не выбран
- **THEN** установка не создаёт команд вне комплекта
- **WHEN** пользователь повторяет регистрацию того же комплекта
- **THEN** принадлежащие Forge неизменённые launchers принимаются без перезаписи чужих файлов

#### Scenario: Конфликт или пользовательская правка
- **GIVEN** найден чужой fride в PATH/каталоге регистрации либо зарегистрированный файл изменён пользователем
- **WHEN** пользователь запускает установку с регистрацией
- **THEN** она сообщает конфликт с путём и завершается ошибкой до изменения комплекта/команд
- **AND** чужие executables, aliases/functions и настройки сохраняются

#### Scenario: Неудачная подготовка
- **WHEN** обязательный setup завершился ошибкой
- **THEN** команда вне комплекта не регистрируется
- **AND** прежний рабочий запуск сохраняется
