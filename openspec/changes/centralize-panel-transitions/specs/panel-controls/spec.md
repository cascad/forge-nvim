## Purpose

Общие команды управления панелями учитывают настоящие окна редактора,
включая открытые штатными командами плагинов, и сохраняют работу программы.

## ADDED Requirements

### Requirement: IDE-PANEL-21 Переходы учитывают штатные окна

Команды IDE SHALL учитывать видимые зарегистрированные панели текущей вкладки
независимо от способа открытия. Show SHALL принимать уже открытый компонент
без пересоздания окна и скрывать остальные компоненты его слота. Hide
конкретного компонента SHALL сохранять другие компоненты. Toggle слота,
общий toggle, focus и code layout SHALL учитывать ту же видимость.
Скрытие SHALL сохранять содержимое, процессы и панели других слотов/вкладок.
При восстановлении общего toggle SHALL возвращаться последний выбранный
компонент каждого слота; если штатные команды создали несколько компонентов
одного слота, выбранный ранее видимый имеет приоритет, иначе первый по ID.

Платформы: все
Проверка: tests/e2e/panel-transitions.test.lua; соседние debug/work/tool/session E2E.

#### Scenario: штатное открытие и общие команды
- **GIVEN** Files открыт через штатный Neotree
- **WHEN** пользователь скрывает левый слот или переключает его видимость
- **THEN** настоящее дерево скрывается, следующий toggle возвращает Files
- **AND** focus слота находит штатное дерево

#### Scenario: явная замена и точечное скрытие
- **GIVEN** в левом слоте штатно открыты панели, а внизу quickfix
- **WHEN** пользователь явно показывает Files
- **THEN** остальные левые компоненты скрыты, quickfix сохранён
- **AND** повторное Show сохраняет окно и буфер Files
- **AND** Hide Files сохраняет другой видимый компонент того же слота

#### Scenario: раскладка и восстановление
- **GIVEN** штатными командами открыты Files и quickfix
- **WHEN** пользователь выбирает code layout
- **THEN** обе панели скрыты, код остаётся в фокусе
- **WHEN** вместо layout пользователь дважды применяет общий toggle
- **THEN** Files и quickfix скрываются и восстанавливаются с прежним содержимым

#### Scenario: границы владения
- **GIVEN** в другой вкладке открыта панель или в текущей работает terminal/DAP
- **WHEN** пользователь скрывает или заменяет панель текущей вкладки
- **THEN** чужая вкладка и процессы сохраняются
