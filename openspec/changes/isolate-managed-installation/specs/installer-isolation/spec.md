## Purpose

Установка Forge рядом с существующим редактором и SDK пользователя, с независимыми файлами, процессным окружением и явным владением каталогом комплекта.

## ADDED Requirements

### Requirement: IDE-BOOT-11 Независимый комплект Forge

Установщик SHALL размещать конфигурацию, runtime, data, state и cache Forge отдельно от обычного Neovim и запускать комплект собственной командой forge. Он MUST не изменять установленные программы, пользовательские PATH, профили shell, обычные конфиги Neovim/WezTerm и системные SDK. Отсутствующий подготовленный runtime MUST давать ошибку без глобального package-manager fallback.
Платформы: все.
Проверка: tests/install-isolation.test.py.

#### Scenario: Установка и запуск рядом с другим Neovim
- **GIVEN** у пользователя есть свой nvim, его конфиг и данные, а также подготовленный runtime Forge
- **WHEN** он устанавливает Forge и запускает forge с аргументами
- **THEN** запускается собственный runtime с config/data/state/cache комплекта
- **AND** существующие файлы, настройки окружения и системные программы остаются неизменными
- **AND** код возврата Neovim передаётся вызывающему процессу

#### Scenario: Занятый целевой каталог
- **GIVEN** выбранный целевой каталог содержит чужие файлы или является ссылкой на другой каталог
- **WHEN** пользователь запускает установку
- **THEN** она завершается ошибкой до перезаписи этих файлов

#### Scenario: Нет совместимого runtime
- **WHEN** подготовленный native runtime не предоставлен и проверенный artifact недоступен
- **THEN** установка завершается ненулевым кодом с указанием отсутствующего artifact
- **AND** системный nvim и глобальные package managers не используются вместо него

#### Scenario: Повтор и ошибка подготовки
- **GIVEN** в каталоге уже установлен Forge
- **WHEN** выполняется повторная установка
- **THEN** прежняя конфигурация сохраняется в backup и данные Forge не удаляются
- **AND** ошибка подготовки не объявляется успешной установкой и прежний работающий запуск сохраняется
