## ADDED Requirements

### Requirement: IDE-FILE-11 Результат поиска открывается в окне кода

IDE SHALL открывать выбранный через `Ctrl+P` файл после `Enter` в окне кода.
Исходное окно кода остаётся назначением, если оно открыто. Защищённая панель
остаётся со своим буфером. Файловый переход из поиска текста также открывает
документ в коде с найденной позицией.

Платформы: все.
История: FIXLOG §311.
Проверка: tests/e2e/acceptance-navigation.test.lua.

#### Scenario: Поиск из кода

- **GIVEN** открыты два окна кода
- **WHEN** пользователь вызывает Ctrl+P и подтверждает другой файл
- **THEN** файл открывается в выбранном окне кода и соседнее окно сохраняется.

#### Scenario: Поиск из Files

- **GIVEN** курсор находится в защищённой панели Files
- **WHEN** пользователь открывает Ctrl+P и подтверждает найденный файл
- **THEN** фокус переходит в код с найденным файлом
- **AND** Files сохраняет окно, буфер и защиту.

#### Scenario: Поиск текста из панели

- **WHEN** пользователь выбирает совпадение по содержимому из панели
- **THEN** редактор открывает файл на строке совпадения.
