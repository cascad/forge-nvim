## Context

По умолчанию `get_selection_window` возвращает `0`. Telescope выполняет
открытие в текущем окне, которым после закрытия списка становится окно
запуска. `ide.buffers.editor_window` уже выбирает текущий split кода либо
находит окно кода, когда фокус в панели.

## Goals / Non-Goals

Цель — открыть выбранный файл в окне кода. Список, фильтрация, сортировка,
обработка `Enter` и защита служебных окон остаются за своими компонентами.

## Decisions

Передать `editor_window` штатному `get_selection_window` для действий открытия
результата Telescope. Callback вызывается после закрытия списка и возврата
в исходное окно. Выбор окна кода применяется также к файловым переходам из
поиска по содержимому. Отмена оставляет фокус в исходном окне.

## Risks / Trade-offs

Проверить открытие из защищённой панели, из выбранного split и поиск по
содержимому с переходом на найденную строку. Прежние проверки палитры и Alt+B
остаются в пакете приёмки.
