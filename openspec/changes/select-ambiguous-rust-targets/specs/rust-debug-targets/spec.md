## Purpose

Предсказуемый запуск Rust проекта с несколькими исполняемыми Cargo целями и явной отменой выбора до старта отлаживаемой программы.

## ADDED Requirements

### Requirement: IDE-DAP-7 Выбор неоднозначной цели Cargo
Редактор SHALL предлагать пользователю выбрать Cargo target, если существующие правила запуска Rust не определяют единственную цель, и прерывать запуск при отмене.
Платформы: все.
Проверка: tests/e2e/rust-language.test.lua.

#### Scenario: Выбор executable из нескольких целей
- **GIVEN** открытый Rust helper/library файл и несколько подходящих bin/example без однозначного default
- **WHEN** пользователь запускает обычную Rust debug configuration
- **THEN** отображается список имён и видов целей
- **AND** после выбора запускается выбранная программа, а не первая цель списка

#### Scenario: Отмена выбора
- **GIVEN** список неоднозначных целей Cargo
- **WHEN** пользователь отменяет выбор
- **THEN** отлаживаемая программа не запускается и активная DAP-сессия не остаётся
- **AND** следующий запуск позволяет заново выбрать цель

#### Scenario: Существующие однозначные маршруты
- **GIVEN** target совпадает с текущим source, найден bin имени package либо единственная цель
- **WHEN** пользователь запускает debug
- **THEN** сохраняется прежний автоматический выбор
- **AND** явный program в launch.json не заменяется выбором из Cargo metadata
