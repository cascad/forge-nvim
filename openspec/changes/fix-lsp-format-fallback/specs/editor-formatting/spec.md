## Purpose

Форматирование документа использует доступные языковые инструменты и сохраняет
полезную очистку текста, даже когда часть инструментов на машине отсутствует.

## ADDED Requirements

### Requirement: IDE-FMT-1 Языковой formatter и LSP fallback
Редактор SHALL форматировать документ доступным настроенным внешним языковым
formatter. Если внешние formatter недоступны, но подключён LSP formatter,
редактор SHALL использовать его; общая очистка пробелов MUST NOT блокировать
этот fallback. При отсутствии обоих общая очистка SHALL сохраняться.
Space l f, команда Format и сочетание форматирования документа SHALL применять
одну политику, результат SHALL сохраняться обычной записью файла.
Платформы: все
Проверка: tests/e2e/go-language.test.lua (gofumpt, gopls fallback, common trim)

#### Scenario: Внешний инструмент доступен
- **WHEN** пользователь форматирует Go документ с доступным gofumpt
- **THEN** используется внешний formatter и файл сохраняет форматированный код

#### Scenario: Только LSP formatter
- **GIVEN** Go LSP подключён, golines/gofumpt отсутствуют
- **WHEN** пользователь форматирует документ любым общим маршрутом
- **THEN** код форматируется LSP и общая очистка не подменяет языковое действие

#### Scenario: Только очистка
- **GIVEN** языковые formatter и LSP отсутствуют
- **WHEN** пользователь форматирует документ с хвостовыми пробелами/пустыми строками
- **THEN** общая очистка выполняется без установки инструментов и потери кода
