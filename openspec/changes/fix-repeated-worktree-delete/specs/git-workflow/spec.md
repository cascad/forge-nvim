## Purpose

Фоновое чтение Git-объектов сохраняет адресацию выбранного репозитория и доступность удаления worktree, когда для самого чтения рабочая папка не требуется.

## ADDED Requirements

### Requirement: IDE-GIT-9 Удаление при живом чтении Git-объекта
Редактор SHALL позволять удалить чистый linked worktree во время собственного фонового чтения Git-объекта, не удерживая без необходимости каталог worktree; чтения и последующие изменения используют выбранный репозиторий.
Платформы: все
Проверка: tests/e2e/gitsigns-live-read.test.lua

#### Scenario: Git ещё работает во время удаления
- **GIVEN** открыт файл linked worktree и фоновый Git читает его объект, процесс ещё жив
- **WHEN** пользователь подтверждает удаление чистого worktree
- **THEN** удаление завершается без ложного требования force из-за cwd этого object read
- **AND** после доставки результата текст доступен без traceback/hit-enter, main stage/unstage работают

#### Scenario: Разные HEAD и отказ от force
- **GIVEN** main и linked имеют разные HEAD и linked содержит незакоммиченное изменение
- **WHEN** пользователь отказывается от force удаления при незавершённом object read
- **THEN** worktree и текст сохраняются, signs завершаются по версии linked
- **AND** stage/unstage меняют именно linked index, main HEAD и index остаются прежними

#### Scenario: Редактор уже находится в удаляемом worktree
- **GIVEN** cwd редактора равен linked и его фоновое чтение Git-объекта ещё работает
- **WHEN** пользователь подтверждает удаление этого worktree
- **THEN** object read не удерживает унаследованный linked cwd, удаление завершается
- **AND** текст сохраняется, последующее редактирование и stage main доступны
