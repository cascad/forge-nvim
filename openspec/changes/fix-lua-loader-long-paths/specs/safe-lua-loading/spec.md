# Spec Delta

## Purpose

Надёжная загрузка конфигурации и Lua modules на длинных Unicode путях позволяет запускать и устанавливать IDE в выбранном пользователем каталоге без зависимости от вспомогательного bytecode cache.

## ADDED Requirements

### Requirement: IDE-BOOT-25 Загрузка Lua на длинных Unicode путях

IDE SHALL запускаться и загружать Lua modules из допустимых для ОС длинных путей с Unicode и пробелами; вспомогательный дисковый bytecode cache MUST NOT прерывать запуск.

Платформы: все. Проверка: tests/install-lua-cache.test.py на Windows/Ubuntu; native macOS отдельно владельцем.

#### Scenario: Полный запуск
- **GIVEN** конфигурация и плагины находятся в длинном Unicode пути
- **WHEN** запускается редактор
- **THEN** доступны штатные плагины и редактирование файлов без cache filename error
- **AND** запуск не устанавливает инструменты в фоне

#### Scenario: Lua source изменился
- **WHEN** пользователь загружает Lua module, изменяет исходник и повторно загружает его
- **THEN** выполняется новая версия исходника без устаревшего bytecode

#### Scenario: Повторный запуск и изоляция
- **WHEN** редактор запускается повторно
- **THEN** он снова готов к работе на таком пути
- **AND** обычный Neovim, его runtime и пользовательские SDK не изменяются
