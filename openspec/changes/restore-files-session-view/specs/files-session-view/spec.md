## Purpose

Восстановление рабочего вида дерева Files в проектной сессии без замены native сохранения файлов и вкладок или владельца размещения окон.

## ADDED Requirements

### Requirement: IDE-PANEL-25 Состояние Files в проектной сессии
Редактор SHALL восстанавливать видимость, корень, раскрытые каталоги, выбранный узел, прокрутку и ширину Files для каждой сохранённой вкладки при повторном открытии проекта и A→B→A.
Платформы: все.
Проверка: tests/e2e/session-files-view.test.lua, tests/e2e/project-session.test.lua, tests/e2e/session-legacy.test.lua.

#### Scenario: Повторный вход и несколько вкладок
- **GIVEN** проект с файлами и разным состоянием Files в двух вкладках
- **WHEN** редактор закрывается штатно, затем сессия открывается снова
- **THEN** файлы и вкладки восстановлены native session
- **AND** Files возвращается с теми же раскрытиями, выбранным узлом, прокруткой и шириной при том же размере UI
- **AND** скрытый Files остаётся скрытым, фокус остаётся в коде
- **AND** возврат фокуса в тот же файл не сбрасывает просмотр дерева; новый файл по-прежнему отслеживается

#### Scenario: Переключение A → B → A
- **GIVEN** два проекта с разными видами Files
- **WHEN** пользователь переключается в B и обратно в A
- **THEN** каждый проект сохраняет своё состояние дерева
- **AND** повторное exit-сохранение не заменяет снимок состоянием уже очищенных окон

#### Scenario: Изменённый диск и старые сессии
- **GIVEN** выбранный ранее узел исчез либо у сессии нет подходящего снимка
- **WHEN** пользователь восстанавливает проект
- **THEN** отсутствующий узел не ломает дерево, допустим fallback к корню
- **AND** сессия без снимка или с изменённым session file использует прежний безопасный restore
- **AND** при меньшем UI ширина адаптируется без восстановления живого процесса
