# Proposal

## Why

В этапе 5 IDE_ROADMAP Git уже представлен Neogit и Diffview, но общий маршрут панелей заканчивается на Files/Outline/DAP. Путь пользователя от изменения до worktree и push не защищён e2e. Требования IDE-GIT-1/2/3 и IDE-PANEL-5 закрепляют этот путь без нового Git backend.

## What Changes

- `Space w g` открывает/фокусирует Neogit справа; статус получает общие q/Esc/zoom/help, штатные Git-действия сохраняются.
- Реальные e2e проходят stage/unstage, diff/историю, ветку, commit/push и worktree через интерфейс; push направлен только в частный локальный bare remote.
- Проверяются отказ удаления dirty worktree и сохранение файла/окон при возврате из Git.
- Корень рабочей папки меняется явно; фокус в старый файл больше не отменяет выбранный worktree через автоопределение project.nvim.
- Руководство, план, команды и история фиксируют результаты Windows/Ubuntu и границы проверки.
- Merge/rebase-конфликты, SSH/auth и физические клавиши терминала остаются следующими проверками этапа 5.

## Capabilities

### New Capabilities

- `git-workflow`: клавиатурный Git-путь, панели, ветки и worktree.

### Modified Capabilities

Нет: основные спеки редактора пока находятся в активных изменениях базовой линии.

## Impact

Neogit/Diffview остаются закреплёнными зависимостями. Neogit обновляется с 395ac481 до d7bb91b4: upstream #1977 исправляет абсолютный Windows-путь в hunk patch. Меняются адаптеры панелей, хоткеи, документация и e2e; новые OS-specific реализации Git не вводятся. Тестовые commit/push работают только с временными репозиториями, рабочий репозиторий не коммитится.
