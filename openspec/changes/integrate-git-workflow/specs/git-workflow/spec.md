## Purpose

Общий клавиатурный путь работы с Git в терминальной IDE на Windows, macOS и Ubuntu: изменения, история, ветки, worktree и отправка коммитов.

## ADDED Requirements

### Requirement: IDE-PANEL-5 Git в общем управлении панелями
Редактор SHALL открывать Git status справа через `Space w g`, сохраняя штатные операции и отдельный полный tab `Space g g`.
Платформы: все
Проверка: tests/e2e/git-workflow.test.lua

#### Scenario: Фокус, помощь и zoom
- **GIVEN** открыт файл кода
- **WHEN** пользователь открывает status, вызывает помощь, разворачивает/возвращает панель и нажимает Esc или q
- **THEN** фокус возвращается в код, выбранная строка и файл сохраняются, Git index и HEAD не меняются
- **AND** штатная справка доступна через g?

### Requirement: IDE-GIT-1 Изменения и история
Редактор SHALL предоставлять stage/unstage, просмотр diff и истории через клавиатуру с возвратом к исходному файлу.
Платформы: все
Проверка: tests/e2e/git-workflow.test.lua

#### Scenario: Изменённый файл
- **GIVEN** файл отличается от HEAD
- **WHEN** пользователь выполняет stage, unstage и открывает diff/историю
- **THEN** index меняется согласно действию, обе версии и коммиты доступны в интерфейсе
- **AND** закрытие просмотра возвращает исходный tab и файл

### Requirement: IDE-GIT-2 Ветка, commit и push
Редактор SHALL предоставлять создание/выбор ветки, ввод сообщения commit и push через клавиатурный интерфейс.
Платформы: все
Проверка: tests/e2e/git-workflow.test.lua (частный локальный bare remote)

#### Scenario: Отправка изменения
- **GIVEN** настроены identity и origin, изменение staged
- **WHEN** пользователь создаёт ветку, вводит сообщение commit и выполняет push
- **THEN** локальный HEAD и remote branch содержат соответствующий commit и содержимое файла

### Requirement: IDE-GIT-3 Worktree и отказ удаления с изменениями
Редактор SHALL предоставлять список, создание, посещение и удаление worktree, сохраняя изменения при отказе от принудительного удаления.
Платформы: все
Проверка: tests/e2e/git-workflow.test.lua

#### Scenario: Путь с пробелом
- **GIVEN** Git-репозиторий с commit
- **WHEN** пользователь создаёт worktree в пути с пробелом, посещает основной и созданный worktree
- **THEN** Git видит отдельную ветку, а status действует относительно выбранного worktree

#### Scenario: Dirty worktree
- **GIVEN** worktree содержит изменённый файл
- **WHEN** пользователь запрашивает удаление и отказывается от force
- **THEN** каталог и содержимое файла сохраняются
- **AND** после явного приведения worktree в чистое состояние обычное удаление удаляет его из списка

### Requirement: IDE-GIT-4 Стабильный корень рабочей папки
Редактор SHALL сохранять явно выбранный cwd при переключении на уже открытые файлы другого worktree; явное открытие проекта, посещение worktree и ProjectRoot могут менять корень.
Платформы: все
Проверка: tests/e2e/git-workflow.test.lua

#### Scenario: Код после создания worktree
- **GIVEN** открыт файл основного worktree и выбран новый worktree
- **WHEN** пользователь возвращает фокус в код и открывает файл по относительному пути
- **THEN** файл открывается из выбранного worktree, а старый буфер сохраняется
- **AND** commit/push относится к новому worktree, HEAD основного worktree не меняется
- **AND** исходная и выбранная рабочие папки доступны в Recent Projects
