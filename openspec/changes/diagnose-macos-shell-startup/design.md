## Context

Рабочая машина этой сессии — Windows; Mac напрямую недоступен. Владелец
подтвердил zsh и воспроизведение до nvim. Ошибка Go объясняет неудачную
проверку скачанного toolchain, но не указывает вызывающую команду.

## Goals / Non-Goals

Goals: получить короткий воспроизводимый отчёт с Mac одной командой,
не создающей новых загрузок; выявить места вызовов Go, prompt и source.

Non-Goals: исправлять профили без доступа к ним, автоматически переустанавливать
Go, менять GOSUMDB/GOTOOLCHAIN глобально, объявлять Starship доказанной причиной,
менять автоустановку Neovim в этом диагностическом change.

## Decisions

1. Python 3, только стандартная библиотека; никакого subprocess/eval.
   Скрипт читает файлы и печатает отчёт, ничего не записывает.
2. Отчёт по профилям содержит путь, номер строки и категорию совпадения,
   но не исходные строки профилей и не полный environment. Значения выбранных
   переменных Go нужны для диагностики; вывод остаётся текстом для проверки.
3. Следуем только статически разрешимым source-путям; командные подстановки,
   globs, неизвестные переменные не выполняем, а отмечаем как динамические.
   Ограничиваем число/размер файлов, устраняем циклы.
4. Сканирование source — эвристика, не интерпретатор zsh. Строки внутри
   функций/условий могут не исполняться; динамические плагины требуют trace.
5. Тесты работают на временных HOME без реального Go или zsh и доказывают
   отсутствие исполнения профилей. Ручная проверка Mac остаётся открытой.

## Risks / Trade-offs

- Статический отчёт не измеряет prompt и не доказывает причинность.
  Следующий этап — точечный trace найденного hook и замеры на Mac.
- HOME и пути проекта могут попадать в отчёт; строки с секретами из профилей
  не выводятся. Имена/пути перед пересылкой можно сократить.
- Если Python 3 на Mac отсутствует, используется прежний ручной лист;
  ради диагностики ничего автоматически не устанавливаем.

## Migration Plan

Запустить скрипт из проблемного каталога на Mac; получить отчёт и локальный
trace по необходимости. Точечный fix и его проверку оформить по фактам.
Откат инструмента не затрагивает shell или редактор.

## Open Questions

Какие конкретно hook/файл и настройки toolchain вызывают исходную задержку —
ответ даст выполнение на Mac, а не предположение по исходникам Windows.
