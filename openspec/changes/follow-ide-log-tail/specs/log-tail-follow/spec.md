## ADDED Requirements

### Requirement: IDE-LOG-6 Последние сообщения и сохранение чтения истории
IDE SHALL при явном открытии скрытой Logs панели показывать последние записи
в обычном хронологическом порядке. Обновления MUST следовать за хвостом только
при cursor на последней строке; чтение истории MUST сохранять native view.
Explicit смена source/filter SHALL показывать конец нового результата.
Восстановление сохранённого Logs view проекта MUST иметь приоритет над default
позицией открытия.
Платформы: все.
История: FIXLOG §307.
Проверка: tests/e2e/ide-logs.test.lua; tests/e2e/session-logs-view.test.lua.

#### Scenario: Открытие и переоткрытие
- **GIVEN** история длиннее высоты панели
- **WHEN** пользователь открывает Logs, затем скрывает и открывает снова
- **THEN** последние сообщения видны без ручной прокрутки.

#### Scenario: Новые сообщения и чтение истории
- **WHEN** новые сообщения приходят при cursor в конце
- **THEN** виден новый конец без смены фокуса
- **WHEN** пользователь отходит вверх
- **THEN** следующее обновление не меняет его cursor/topline/leftcol.

#### Scenario: Другой источник и восстановление сессии
- **WHEN** выбран другой native source или изменён фильтр
- **THEN** виден конец нового результата
- **WHEN** загружается сохранённая сессия с позицией чтения Logs
- **THEN** возвращается сохранённый view и размер панели.
