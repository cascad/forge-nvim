## Context

Старая папка содержит ранние Helix/Neovim narrative-документы, справочники,
копии кода и служебные данные. Сборка развивается в F:/repo/forge-nvim.
Многие ранние документы не датированы; четыре совпадают с резервным
снимком, чьё имя содержит дату 2026-05-11.

## Goals / Non-Goals

Goals: сохранить уникальную описательную историю и одну точку чтения;
проверить целостность; не придумывать даты/проверки; закрепить формат исправлений.

Non-Goals: переносить код, исполнять старые команды, удалять прежний снимок,
переписывать старые FIXLOG-записи, превращать старые планы в текущие требования.

## Decisions

Архив хранит исходные байты (-text в .gitattributes). Manifest сохраняет
raw SHA256 и нормализованный хеш для группировки CRLF/LF-дублей. Хронология
ссылается на существующие журналы вместо дублирования их полного текста.
Неизвестные даты остаются неизвестными; дата снимка/импорта/фиксации в git
отделяется от даты события. Импортируются только описательные артефакты.
Новые исправления получают вывод и проверку/e2e с указанием среды.

## Risks / Trade-offs

Архив содержит устаревшие пути/примеры/API; это явно описано в README архива.
Старые проверки не являются доказательством нынешней сборки. Legacy-копии
не поддерживаются как актуальные руководства. Исходный workspace остаётся
снимком; все новые записи ведутся в рабочем репозитории.

## Migration Plan

Сверить источники и дубли, скопировать выбранные материалы, построить index,
проверить хеши/полноту/ссылки, дописать FIXLOG §59. Это документальный перенос,
для него нужны проверки целостности, а не e2e редактора.

## Open Questions

Точные даты недатированных ранних событий не установлены и не требуются
для сохранения источников; при появлении доказательств добавляется уточнение.
