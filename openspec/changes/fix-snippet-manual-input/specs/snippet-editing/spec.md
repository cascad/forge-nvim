## Purpose

Позволяет отказаться от предлагаемых параметров принятой сигнатуры при
ручном вводе, сохраняя собственный код и привычные переходы между полями.

## ADDED Requirements

### Requirement: IDE-SNIP-1 Ручной ввод после выхода из поля сигнатуры

Редактор SHALL при первом ручном вводе вне текущего поля незавершённой
сигнатуры удалить нетронутые предлагаемые параметры и завершить её
snippet-сессию. Введённые аргументы и новый текст MUST сохраняться.
Одно лишь движение курсора MUST NOT менять код. Обычный ввод в активное
поле и Tab/Shift-Tab MUST продолжать штатное заполнение сигнатуры.
Завершённый вызов, обычный код и другие буферы MUST NOT очищаться.

Платформы: все
Проверка: tests/e2e/snippet-input.test.lua (IDE-SNIP-1)

#### Scenario: ручной ввод после принятой сигнатуры
- **GIVEN** completion вставил combine(left, right) и выделил left
- **WHEN** пользователь уходит за вызов и вводит новый текст
- **THEN** остаются combine() и новый текст, нетронутые left/right удалены
- **AND** движение до первого ввода само по себе не меняет текст

#### Scenario: сохранение уже введённого аргумента
- **GIVEN** первый параметр заменён пользовательским выражением
- **WHEN** пользователь уходит из активного поля и начинает ручной ввод
- **THEN** введённый аргумент сохраняется, нетронутый параметр и лишний
  разделитель исчезают, новый текст остаётся на месте ввода

#### Scenario: ручной ввод в неактивный параметр
- **GIVEN** курсор вручную перенесён в нетронутый неактивный параметр
- **WHEN** пользователь печатает своё значение
- **THEN** старый текст этого параметра удалён, новое значение и нужный
  разделитель сохранены, остальные нетронутые параметры убраны

#### Scenario: заполнение и завершение
- **WHEN** пользователь заполняет поля, использует Tab/Shift-Tab и завершает
  snippet обычным переходом за последний параметр
- **THEN** заполненный вызов сохраняется при дальнейшем вводе
- **AND** явный Esc на активном поле по-прежнему сворачивает вызов

#### Scenario: границы очистки
- **WHEN** ввод идёт в обычном коде, другом буфере или в сложном шаблоне
  с блоком/динамическими узлами вместо списка параметров вызова
- **THEN** произвольный код не удаляется по поиску ближайших скобок
- **AND** отмена простой сигнатуры доступна для undo вместе с ручным вводом
