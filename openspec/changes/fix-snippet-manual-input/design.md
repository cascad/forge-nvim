## Context

См. proposal.md и FIXLOG §29–30. LuaSnip/cmp закреплены lock-файлом;
ext_opts выделяют active/passive. Существующий Esc чистит весь вызов через
ci( по явной команде. Этот путь сохраняем; автоматический ввод требует
точных границ узлов и сохранения изменённых аргументов.

## Goals / Non-Goals

Goals: воспроизвести реальную cmp/LuaSnip цепочку, очищать только предложения
простой сигнатуры при ручном вводе вне активного поля, с undo и без OS-веток.
Non-Goals: замена completion engine, LSP/signature-help UI, новый snippet
parser, изменение прежнего явного Esc и очистка произвольных шаблонов кода.

## Decisions

- Сначала красный E2E с fixture .code-snippets, загруженной штатным VSCode
  loader. Ввод через cmp_luasnip → выбор → Enter; LuaSnip и cmp не подменяются.
  Это проверка редакторского completion/snippet, не качества ответов gopls.
- Helper слушает документированные LuaSnip User events. Использование
  node/mark отделено в одном модуле и проверяется на pinned LuaSnip.
  Сравнение текста и наблюдение правок отличают нетронутое предложение от ввода.
- Очищается только распознанный линейный список insert-параметров между
  статическими скобками вызова и comma-разделителями. Для сложных шаблонов
  возможен unlink с сохранением текста; ci( при автоматической отмене не нужен.
- Текст изменяется перед первым ручным символом вне active node. InsertCharPre
  имеет textlock: удаление откладывается командой в typeahead перед исходным
  символом. Символ не теряется, последующий ввод не обгоняет отмену.
- Удаляются точные node-ranges и только лишние разделители. При вводе в
  passive-поле сохраняется пустой слот, в который попадёт новый символ.
  Курсор отслеживается extmark; правки объединены с новым вводом для undo.
- Состояние привязано к buffer/snippet, очищается при завершении/удалении.
  Никаких глобальных перехватов обычного ввода, скачиваний или OS-условий.

## Risks / Trade-offs

- LuaSnip mark API → компактная граница интеграции, pinned версия и real E2E;
  недоступный/сложный range не оправдывает удаление окружающего текста.
- Select mode, Unicode, typeahead, undo → отдельные сценарии; не заменять
  пользовательский ввод прямым вызовом функции очистки в тесте.
- Похожие параметры, уже завершённый snippet и другой буфер → наблюдение
  изменений, buffer-local состояние и проверки сохранности текста.
- Mac/доставка клавиш через WezTerm → явно непроверено до прогона владельца.

## Migration Plan

Новых зависимостей и установок нет. Обновление конфигурации и перезапуск
Neovim; откат helper/config. Артефакты и E2E остаются в репозитории.
