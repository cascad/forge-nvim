## Purpose

Проверить постоянную цельную рамку на настоящих Locals и коде до решения
о распространении оформления на все рабочие панели IDE.

## ADDED Requirements

### Requirement: IDE-PANEL-20 Явный рабочий пилот рамок Locals
Редактор SHALL предоставлять явно включаемый эксперимент рамок Code/Locals
с живыми данными текущей остановленной DAP-сессии и возвратом обычной раскладки.
Платформы: все. Проверка: tests/e2e/frame-layout.test.lua.

#### Scenario: Живые переменные и остановки
- **GIVEN** реальная остановленная отладка с Locals
- **WHEN** пользователь включает пилот, раскрывает переменную, выполняет шаг и Continue
- **THEN** обновляются настоящие значения и строка следующей остановки
- **AND** Code и Locals имеют неперекрывающиеся области и цельные рамки
- **AND** нет второго видимого или скрытого source-окна Locals

#### Scenario: Клавиатура и resize
- **GIVEN** пилот включён
- **WHEN** пользователь использует Space w h/j/k/l/0/d/c/q/z/? и меняет размер UI
- **THEN** сохраняются фокус, помощь, вывод и скрытие/повторное открытие
- **AND** zoom Locals изменяет то же окно, сохраняя выбранную переменную
- **AND** слишком маленькая область возвращает обычную раскладку с понятным сообщением

#### Scenario: Ограниченная область и выход
- **GIVEN** пилот не является default layout
- **WHEN** пользователь выключает его, меняет tab или сохраняет сессию
- **THEN** обычное окно кода восстановлено, pilot окна/обработчики освобождены
- **AND** буферы, DAP-сессия и output не уничтожены
- **AND** включение без остановленной сессии не меняет раскладку
