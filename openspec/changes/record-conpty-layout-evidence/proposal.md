## Why

IDE-039: полная ConPTY-проба дважды разошлась с RU fixture только на Ctrl+/,
а следующий EN повтор прошёл. Обычный FAIL не сохраняет результат и точный
diff; язык переднего окна сам по себе не доказывает раскладку каждой ConPTY.

## What Changes

- Добавить отдельную диагностическую команду над настоящим неизменённым
  `chords.test.py`: полный результат, ожидаемый JSON, diff, provenance и
  метаданные сессий в новом ignored каталоге каждого запуска.
- Сохранять исходный exit code и строгие проверки, включая расхождение.
- Проверить настоящий PASS и намеренно неверный частный эталон; убедиться,
  что диагностика не меняет ни исходный fixture, ни пользовательский профиль.
- Записать отрицательные результаты расследования и продолжение IDE-039.

## Capabilities

### New Capabilities

Нет: только диагностический инструмент и документация (`skip_specs: true`).

### Modified Capabilities

Нет. Контракты WT-KBD-9/WT-KEYS-10, runtime и эталоны остаются прежними.

## Impact

`tests/diagnostics/`, документация, FIXLOG/HISTORY и очередь. Windows ConPTY
запускается с SDK общего runner; на других ОС явный SKIP. Docker/WSL lifecycle,
фокус окон и настройки раскладки инструмент не меняет. IDE-039 остаётся
открытым до доказанного воспроизведения и исправления причины.
