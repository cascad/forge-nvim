## Purpose

Клавиатурное разрешение Git-конфликтов в терминальной IDE позволяет видеть
обе версии, редактировать результат и явно завершать либо отменять операцию.

## ADDED Requirements

### Requirement: IDE-GIT-11 Конфликты merge и rebase
Редактор SHALL предоставлять клавиатурный путь запуска merge/rebase,
просмотра конфликта, выбора/редактирования результата, stage и продолжения,
а также явной отмены с восстановлением исходной ветки и файлов.
`Alt+e` в Diffview SHALL фокусировать редактируемый результат, включая
трёхсторонний conflict view, а не read-only версию.
Платформы: все
Проверка: tests/e2e/git-conflicts.test.lua

#### Scenario: Merge конфликт и завершение
- **GIVEN** две локальные ветки независимо изменили одну строку
- **WHEN** пользователь запускает merge, открывает Diffview, выбирает версию и сохраняет/stage/continue
- **THEN** результат доступен для ввода через Alt+e, conflict markers удалены
- **AND** merge commit содержит обе исходные вершины, index чист, исходная другая ветка сохранена

#### Scenario: Отмена merge
- **WHEN** пользователь подтверждает Abort после merge-конфликта
- **THEN** восстанавливаются исходный HEAD, index и рабочий файл, обе ветки сохраняются

#### Scenario: Rebase конфликт и завершение
- **GIVEN** локальная ветка имеет commit, конфликтующий с новой основой
- **WHEN** пользователь запускает rebase, разрешает конфликт через Diffview, сохраняет/stage/continue
- **THEN** операция завершается на новой основе с выбранным результатом и чистым index
- **AND** исходная ветка новой основы не меняется

#### Scenario: Отмена rebase
- **WHEN** пользователь подтверждает Abort после rebase-конфликта
- **THEN** исходная ветка, HEAD, index и рабочий файл восстанавливаются
