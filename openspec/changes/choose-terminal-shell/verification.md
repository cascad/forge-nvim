# Проверка IDE-153 / IDE-PANEL-33

Рабочий тест `tests/e2e/terminal-shell.test.lua` открывает настоящее меню
клавиатурой, выбирает найденный cmd / sh, задаёт расположенный отдельно бинарь
с пробелами в пути, выполняет команду в каждой консоли и проверяет живые job ID
предыдущих терминалов. Неверный путь сохраняет прошлое значение. Auto удаляет
настройку. Глобальная `vim.o.shell` сохраняется.

Windows и Ubuntu — по 3 PASS с учётом точечных повторов, по 2 пропуска веток
другой платформы. Windows использовал настоящий PowerShell 7 и cmd,
Ubuntu — Bash и sh. Проверены 9 записей о завершении редактора. Логи в
`.tests/terminal-choice`. macOS остаётся для ручного прогона.

В промежуточных запусках проявились разбор начальных кавычек в cmd и потеря
режима ввода при размещении двух видимых терминалов. Для cmd путь запускается
с префиксом `@`, а новая консоль занимает штатную нижнюю панель. Предыдущие
консоли доступны через `:TermSelect`. В POSIX тестовая копия бинаря заменила
symlink, поскольку сбор артефактов ожидает обычные файлы. Проверка готовности
PTY ждёт приглашения, чтобы первая команда не терялась при старте оболочки.

Strict OpenSpec и trace прошли. Изменения клавиш описаны в
[`docs/FRIDE_KEYBOARD_GUIDE.md`](../../../docs/FRIDE_KEYBOARD_GUIDE.md).

baseline `95b5c59`. Резервная копия в
