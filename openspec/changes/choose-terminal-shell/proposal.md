## Why

IDE-153. Встроенный Terminal выбирает оболочку по платформе. Пользователь хочет
видеть доступные оболочки и указывать конкретный бинарь при нескольких установках.
IDE-PANEL-33 добавляет явный выбор поверх автоматического режима IDE-PANEL-19.

## What Changes

- Настройка оболочки предлагает Auto, найденные системные оболочки и ввод пути.
- Настройка применяется к новым терминалам. Меню сохраняет её для профиля fride.
- Команда создания новой консоли позволяет сразу проверить выбор.

## Capabilities

### New Capabilities

- `terminal-shell-selection`

### Modified Capabilities

Нет. Правило IDE-PANEL-19 описывает Auto.

## Impact

Настройки профиля, конфигурация ToggleTerm, native console E2E и руководство.
