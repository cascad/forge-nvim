## Context

ToggleTerm принимает функцию shell, которую вызывает при старте процесса.
fride хранит пользовательские пути в tools.json и поддерживает выбор через
vim.ui.select и vim.ui.input.

## Goals / Non-Goals

Цель — дать выбор оболочки для встроенных консолей, в том числе для новой
консоли без остановки уже открытой. Терминал WezTerm и shell для Ex-команд,
задач и инструментов остаются за пределами этого изменения.

## Decisions

Хранить абсолютный путь `terminal-shell` в пользовательском tools.json.
Auto удаляет этот ключ. Проектный tools.json не выбирает интерактивный shell.
Показывать доступные оболочки из PATH и из /etc/shells на POSIX. Проверять
ручной путь до записи. Если сохранённый бинарь исчез, предупреждать и
запускать Auto. Новую консоль создаёт штатный ToggleTerm Terminal:new.

## Risks / Trade-offs

ToggleTerm запускает shell командой. Проверяем запуск пути с пробелом,
фактическое выполнение команд и прежний job при изменении предпочтения.
