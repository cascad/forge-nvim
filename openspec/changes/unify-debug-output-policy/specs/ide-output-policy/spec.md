# Spec Delta

## Purpose

Единый доступ к выводу отладки через клавиатуру: канал соответствует запуску, а скрытие и ручное открытие сохраняют уже полученный текст.

## ADDED Requirements

### Requirement: IDE-PANEL-11 Выбор и восстановление Debug Output

Редактор SHALL выбирать канал по конфигурации при запуске и возвращать видимый либо последний выбранный канал при ручном открытии Output/Debug View. Скрытие и продолжение SHALL сохранять буфер, текст и существующий PTY; новый запуск получает свежий PTY согласно действующему lifecycle.

Платформы: все.
Проверка: `tests/e2e/dap-output-policy.test.lua`, существующие language/debug suites.

#### Scenario: Автоматический выбор
- **WHEN** запускается CodeLLDB или конфигурация integratedTerminal
- **THEN** вывод появляется в PTY
- **AND** Go/Delve outputMode=remote имеет приоритет и использует REPL, остальные internalConsole конфигурации используют REPL

#### Scenario: Ручное восстановление
- **GIVEN** вывод уже получен и панель скрыта, включая завершившуюся сессию
- **WHEN** пользователь открывает Debug View или нажимает Space w c / Space D c
- **THEN** возвращается последний канал с прежним текстом без запуска нового debuggee
- **AND** Space D v продолжает открывать Variables

#### Scenario: Явный выбор
- **WHEN** пользователь явно открывает REPL или Console и затем скрывает панель
- **THEN** ручное открытие возвращает этот канал
- **AND** холодное открытие без запусков использует REPL и не запускает отладку

#### Scenario: Продолжение и следующий запуск PTY
- **GIVEN** Rust остановлен на breakpoint и имеет PTY с выводом
- **WHEN** панель скрывают, открывают и продолжают через F5
- **THEN** используется тот же PTY и вывод остаётся доступным
- **AND** следующий запуск создаёт свежий PTY без текста прежнего запуска
