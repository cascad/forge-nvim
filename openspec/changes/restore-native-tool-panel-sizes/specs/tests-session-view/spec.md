## Purpose

Возвращать штатную Tests sidebar в сохранённой вкладке и с прежней шириной, продолжая использовать настоящий discovery и follow существующего Neotest.

## ADDED Requirements

### Requirement: IDE-PANEL-27 Открытость и ширина Tests в сессии
Редактор SHALL возвращать открытость, штатную привязку к вкладке и ширину Tests при восстановлении проекта, используя настоящие позиции тестов и прежний native follow.
Платформы: все.
Проверка: tests/e2e/session-tool-views.test.lua (Tests).

#### Scenario: Quit и восстановление
- **GIVEN** штатное окно Tests открыто в сохранённой вкладке с изменённой шириной
- **WHEN** пользователь перезапускает редактор и восстанавливает проект
- **THEN** Tests виден в той же вкладке и с прежней шириной при том же UI
- **AND** native discovery возвращает настоящие тесты, они не запускаются автоматически
- **AND** скрытая Tests остаётся скрытой, фокус возвращается в код

#### Scenario: Старые данные
- **GIVEN** сессия не содержит новых данных Tests
- **WHEN** пользователь восстанавливает её
- **THEN** прежние Files/Logs/Outline и legacy fallback продолжают работать
- **AND** редактор не создаёт копии внутренних окон или раскрытий Neotest
