## Purpose

Сохранять привычные размеры встроенной консоли и debug-панелей без автоматического запуска shell или отладки при повторном входе в проект.

## ADDED Requirements

### Requirement: IDE-PANEL-28 Размеры Terminal и Debug после явного открытия
Редактор SHALL сохранять высоту встроенной горизонтальной Terminal, ширину debug sidebar и высоту debug Output по проектным вкладкам, в том числе после скрытия панелей; после полного перезапуска они MUST оставаться скрытыми до явного открытия или запуска и только тогда получать сохранённый размер.
Платформы: все.
Проверка: tests/e2e/session-tool-views.test.lua (Terminal, Debug).

#### Scenario: Скрытая консоль
- **GIVEN** пользователь изменил высоту Terminal и скрыл её
- **WHEN** редактор перезапускается и восстанавливает проект
- **THEN** восстановление не открывает Terminal и не создаёт новый shell
- **AND** после явного открытия создаётся штатная консоль с сохранённой высотой
- **AND** в неё можно вводить команды и читать настоящий вывод

#### Scenario: Debug sidebar и Output
- **GIVEN** пользователь изменил ширину sidebar и высоту Output, завершил debug и скрыл панели
- **WHEN** редактор перезапускается и восстанавливает проект
- **THEN** debug-панели и session автоматически не открываются и не запускаются
- **AND** явный следующий debug использует штатный adapter/панели с сохранёнными размерами

#### Scenario: Нативные границы
- **GIVEN** окно заново открыто или размер терминала уменьшился
- **WHEN** применяется сохранённый размер
- **THEN** native layout ограничивает его доступным местом, код остаётся доступен
- **AND** последующее ручное изменение размера не сбрасывается при смене фокуса
