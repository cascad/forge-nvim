# Spec Delta

## Purpose

Позволить работать с кодом и переключать фокус, пока файловое дерево читает
раскрываемый пользователем каталог на медленной файловой системе.

## ADDED Requirements

### Requirement: IDE-FILE-6 Ручное раскрытие Files не ожидает чтения каталога

Сборка SHALL выполнять чтение каталога при ручном раскрытии Files
асинхронно средствами Neo-tree. Пока чтение не завершено, пользователь SHALL
иметь возможность переключиться в код и изменить текст. После чтения Files
SHALL показать реальные дочерние файлы и позволить открыть и сохранить их.

Платформы: все. История: FIXLOG §225.
Проверка: tests/e2e/file-scan-order.test.lua (IDE-FILE-6).

#### Scenario: Ввод во время незавершённого раскрытия

- **GIVEN** открыты текстовый файл и Files с нераскрытым каталогом
- **WHEN** пользователь раскрывает каталог клавишей `l`, а чтение ещё выполняется
- **THEN** переключение `Space w 0` и ввод в файле завершаются до окончания чтения
- **AND** в reference E2E ввод занимает меньше 300ms
- **AND** после завершения чтения дочерний файл можно открыть и сохранить

#### Scenario: Прежние обновления сохраняются

- **WHEN** чтение раскрываемого каталога пересекается с watcher refresh
- **THEN** сохраняются гарантии IDE-FILE-5 о порядке обновлений и реальных файлах
