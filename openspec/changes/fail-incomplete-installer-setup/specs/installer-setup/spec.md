# Spec Delta

## Purpose

Не выдавать отказ обязательной команды подготовки за готовую установленную
IDE и выполнять подготовку именно выбранного профиля конфигурации.

## ADDED Requirements

### Requirement: IDE-BOOT-9 Строгая подготовка установленного профиля

Установщик SHALL выполнять подготовку в контексте установленного профиля,
восстанавливать plugins по lock, применять и проверять все его backports.
Lua/Vim exception либо отсутствие обязательной команды plugins/parsers/tools SHALL завершать установку
с ненулевым кодом без итогового сообщения installed и без следующих stages.
Отсутствующие каталоги пути установки и его родителей SHALL создаваться
автоматически как для Default, так и для пользовательского пути.

Платформы: все. История: FIXLOG §234.
Проверка: tests/install-setup.test.py (native Neovim/installer stand).

#### Scenario: Подготовка выбранного профиля

- **GIVEN** окружение указывает на другой Neovim config
- **WHEN** выбранный профиль устанавливается
- **THEN** restore/backports/parsers/tools используют установленный профиль
- **AND** завершённые команды имеют success exit

#### Scenario: Команда завершилась ошибкой или отсутствует

- **WHEN** обязательная команда бросает ошибку или не найдена
- **THEN** setup возвращает nonzero и не выполняет последующие stages
- **AND** итоговый installed не выводится

#### Scenario: Неизвестный payload backport

- **WHEN** установленный source не соответствует известному backport
- **THEN** native applier отказывает, parsers/tools не запускаются

#### Scenario: Отсутствующий Default или Custom каталог

- **GIVEN** выбранный путь и его родительские каталоги ещё не существуют
- **WHEN** пользователь запускает установку
- **THEN** каталоги создаются автоматически и setup использует новый профиль
