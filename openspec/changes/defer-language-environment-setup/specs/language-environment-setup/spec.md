## Purpose

Дать установить и использовать основу fride без обязательных языковых SDK,
предлагать недостающую среду по первому файлу и сохранять постоянное управление
SDK, инструментами и предложениями на уровне пользователя и проекта.

## ADDED Requirements

### Requirement: IDE-BOOT-50 Явная подготовка языка по потребности

Default/Custom SHALL устанавливать готовую основу IDE без обязательной установки
языковых SDK. Поддерживаемые, но ещё не подготовленные языки SHALL иметь явный
отложенный статус. При первом подходящем файле fride SHALL пассивно обнаруживать
недостающий SDK/IDE tools и ненавязчиво предлагать подготовку; сеть и установка
MUST начинаться только после выбора пользователя. Подготовка SHALL выполняться
асинхронно штатными SDK providers и Mason, не переустанавливать работающий
редактор и не мешать edit/save/panel navigation. Готовые SDK/версии/ручные пути
MUST сохраняться, явная ошибка выбора MUST NOT маскироваться fallback.
Платформы: все; native Mac/WSL отдельно.
Проверка: tests/e2e/language-environments.test.lua, tests/install-language-environments.test.py, tests/install-sdk-actions.test.py.

#### Scenario: Основа IDE без SDK

- **GIVEN** нет Go/Rust/Python/Node и кешей fride
- **WHEN** устанавливается Default либо Custom
- **THEN** основа IDE и выбранные parsers/Terminal имеют строгую readiness
- **AND** отложенные SDK/зависимые tools не скачиваются и не считаются готовыми
- **AND** результат явно различает Core ready и deferred languages

#### Scenario: Первый подходящий файл

- **WHEN** открыт обычный файл поддерживаемого языка и среды/инструментов нет
- **THEN** показана доступная с клавиатуры ненавязчивая подсказка подготовки
- **AND** edit/save работают, нет version/download probes в FileType callback
- **AND** предложение не повторяется на каждом BufEnter в том же проекте/сеансе

#### Scenario: Выбранная подготовка

- **WHEN** пользователь явно запускает подготовку языка
- **THEN** видит native command/source/destination policy и может отменить
- **AND** SDK prerequisites и tools готовятся в отдельном async процессе
- **AND** SDK-зависимые Mason tools готовятся после SDK, с тем же каталогом
- **AND** готовность проверяется строго, exit0/повреждённый результат не считается успехом

#### Scenario: Новая и существующая среда

- **WHEN** на Ubuntu отсутствуют Go либо Rust и выбрана установка
- **THEN** используется официальный готовый Go SDK либо rustup с rustfmt/rust-src
- **AND** обычные SDK homes остаются вне IDE kit, профили/PATH глобально не меняются
- **AND** готовая установленная версия не обновляется/не удаляется без отдельного выбора
- **AND** необходимые APT actions не останавливаются на интерактивном debconf вопросе

#### Scenario: Отказ и применение

- **WHEN** подготовка отменена, завершается ошибкой или другая задача ещё работает
- **THEN** причина/вывод доступны в IDE Logs/задаче, текущие edit/debug/tests не прерываются
- **AND** повтор/настройка остаются доступны; работающая среда не заменяется молча
- **AND** применение новой среды использует существующий явный SDK restart workflow

#### Scenario: Explicit setup и диагностика

- **WHEN** явно запрошена подготовка языка либо --check-sdks/старый direct setup
- **THEN** preflight и postconditions для подготавливаемого набора остаются строгими
- **AND** check-sdks даёт exit2 при nonready, preview не запускает SDK
- **AND** произвольный PATH executable не заменяет подтверждение установки IDE tools

### Requirement: IDE-BOOT-51 Постоянное управление языками и предложениями

Fride SHALL иметь доступный с клавиатуры раздел «Языки и инструменты» через
Space l S и команду, показывать выбранные SDK/version/path/source и состояние
LSP/format/DAP/tests. Раздел SHALL позволять выбрать существующую среду/ручной
путь, подготовить недостающее, повторить проверку и открыть логи. User/project
настройки SHALL иметь явную область/наследование. Later и отключение предложений
для проекта/пользователя MUST быть различимы и обратимы через этот раздел.
Прямой ForgeSdk selector и native Mason UI SHALL сохраняться.
Платформы: все.
Проверка: tests/e2e/language-environments.test.lua.

#### Scenario: Отключённое предложение

- **GIVEN** пользователь выбрал Later либо отключил предложения
- **WHEN** открыт раздел языков
- **THEN** состояние среды и все доступные действия видны без нового FileType
- **AND** предложения можно снова включить для нужной области

#### Scenario: Области и выбор

- **WHEN** задана проектная настройка SDK/path или prompt policy
- **THEN** она имеет приоритет над user scope, источник показан
- **AND** ручной выбор/сброс использует существующие sdk.json/tools.json semantics
- **AND** установка/обновление tools делегируется штатным providers/Mason
