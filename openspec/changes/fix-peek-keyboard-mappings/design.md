# Design

## Context

См. proposal.md. Закреплённый Glance ожидает callbacks в mappings и уже
предоставляет все нужные действия. Сборка передаёт семь строк; nvim исполняет
их как normal-команды. Native диагностика подтвердила E21 на двух ОС.
Сложность проверки — настоящий LSP, свёрнутые группы и ориентация окон.

## Goals / Non-Goals

**Goals:** удалить ошибочное дублирование и проверить наблюдаемое поведение
клавиш на настоящем проекте через существующий native editor driver.

**Non-Goals:** свой LSP, новые плагины/пины, переработка panel framework,
удаление Peek или другой UI без решения владельца, исправление IDE-084.

## Decisions

- Удалить весь mappings override. Использовать defaults закреплённого плагина;
  это меньше поддержки, чем заново перечислять callbacks в собственном config.
- E2E запускает настоящие gopls/Neovim, посылает клавиши и проверяет файлы,
  курсор, preview и геометрию splits. Проверка только типов callbacks не доказывает
  переходы. Ответы LSP не подменяются.
- Небольшой Go fixture без зависимостей содержит функцию с двумя usages,
  интерфейс и реализацию. Изолированные cache/env лежат в тестовом runtime;
  сеть и автоматические установки при старте запрещены тестовым профилем.
- Windows и Ubuntu выполняются последовательно с лимитом Go CPU=2.
  macOS остаётся отдельным native gate, не заменяется контейнером.

## Risks / Trade-offs

- Изменение defaults при будущем обновлении пина → постоянный native regression.
- Свёрнутые reference groups → раскрывать штатной клавишей, выбирать по реальному
  тексту результата и проверять позицию preview, не предполагать порядок LSP.
- Native тайминги → ожидать готовность client/UI, сохранять логи и snapshot.

## Migration Plan

Получить RED нового regression на исходном config, удалить override, выполнить
Windows/Ubuntu проверки, обновить docs/history и закоммитить. Откат — revert
коммита. Архивация только после оставшихся native gates.
