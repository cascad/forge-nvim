# Spec Delta

## Purpose

Peek позволяет просматривать определения и связанные символы, выбирать результат
и переходить в код с клавиатуры, сохраняя понятный возврат к исходному месту.

## ADDED Requirements

### Requirement: IDE-PANEL-9 — клавиатурное управление Peek

Редактор SHALL открывать Peek определений (`gpd`), references (`gpr`), типов
(`gpt`) и реализаций (`gpi`) по ответам подключённого language server.
В списке результатов `j`/`k` SHALL менять выбранную строку и соответствующий
preview; `l`/`h` SHALL раскрывать/сворачивать группу файла. `Enter` SHALL
переходить к выбранному месту; `v`/`s` SHALL открывать его в вертикальном/
горизонтальном split. `q`, `Esc` и `Q` в списке SHALL закрывать Peek без
изменения кода и возвращать фокус/курсор в исходное место. `Space l` SHALL
переключать фокус между списком и preview; `Q` в preview SHALL закрывать Peek.
Эти операции MUST выполняться без ошибок редактирования служебного буфера.

#### Scenario: Закрытие определения
- **WHEN** пользователь открывает `gpd` на вызове функции и нажимает `q` или `Esc`
- **THEN** Peek закрыт, исходный файл и курсор восстановлены, исходники не изменены
- **AND** сообщение E21 отсутствует

#### Scenario: Выбор reference и переход
- **WHEN** пользователь открывает `gpr`, раскрывает группу файла, выбирает usages через `j`/`k` и нажимает `Enter`
- **THEN** preview следует выбранному usage, а переход открывает соответствующий файл и позицию

#### Scenario: Переход в split
- **WHEN** пользователь выбирает определение и нажимает `v` или `s`
- **THEN** Peek закрывается, целевая позиция открыта в split соответствующей ориентации

#### Scenario: Типы и реализации
- **WHEN** language server поддерживает type definition и implementation и пользователь вызывает `gpt` или `gpi`
- **THEN** Peek показывает реальные соответствующие символы из проекта

#### Scenario: Фокус списка и preview
- **WHEN** пользователь открывает Peek и нажимает `Space l` дважды
- **THEN** фокус переходит в preview и обратно в список
- **AND** `Q` из preview закрывает Peek и возвращает исходный код
