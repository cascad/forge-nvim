## Purpose

Дополнение Git-пути терминальной IDE: безопасное закрытие просмотра во время асинхронной загрузки и сохранение контекста редактирования на всех целевых ОС.

## ADDED Requirements

### Requirement: IDE-GIT-5 Закрытие незавершённого просмотра Git
Редактор SHALL возвращать пользователя из загружающегося Diffview в исходный контекст без async error/hit-enter, сохраняя исходные файлы и раскладку; отложенная очистка SHALL относиться только к закрываемому просмотру.
Платформы: все
Проверка: tests/e2e/diffview-close.test.lua

#### Scenario: Закрытие при загрузке версий
- **GIVEN** список истории показан, загрузка версий ещё выполняется
- **WHEN** пользователь закрывает просмотр через Space g q, q, F4/Alt-w или DiffviewClose
- **THEN** фокус возвращается в исходный файл без ожидания завершения Git
- **AND** после завершения операций backend просмотр очищается без ошибок и лишних окон
- **AND** текст, курсор и размеры исходных окон сохраняются

#### Scenario: Повтор и другой просмотр
- **GIVEN** запрос закрытия ещё ожидает безопасной очистки
- **WHEN** пользователь повторяет закрытие и открывает другой просмотр
- **THEN** поздние callbacks первого просмотра не закрывают и не фокусируют второй
- **AND** повторное открытие истории после очистки работает

#### Scenario: Начальная загрузка и готовый просмотр
- **GIVEN** просмотр только создаётся, пуст или уже загружен
- **WHEN** пользователь закрывает его
- **THEN** не возникает зависания/ошибки; исходный контекст остаётся доступен
