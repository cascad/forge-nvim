# Spec Delta

## Purpose

Доставка готового native поиска в составе Core обеспечивает поиск файлов и текста без предварительной установки отдельного ripgrep на машине пользователя.

## ADDED Requirements

### Requirement: IDE-BOOT-26 Готовый поиск Core

Release Core SHALL включать проверенный native ripgrep и лицензии; установленный редактор MUST искать файлы и текст штатными средствами без системного rg/fd.

Платформы: все. Проверка: tests/install-search-runtime.test.py; native Mac отдельно владельцем.

#### Scenario: Native поиск и переход
- **GIVEN** Core установлен без системного rg/fd
- **WHEN** пользователь ищет файл по имени или строку по содержимому
- **THEN** штатный picker показывает результат и открывает соответствующий файл/строку
- **AND** поиск учитывает project ignore rules и Unicode paths

#### Scenario: Частная поставка
- **WHEN** Core устанавливается или запускается повторно
- **THEN** используется доставленный ripgrep с закреплённой версией
- **AND** обычные SDK, global PATH и существующие пользовательские программы не изменяются

#### Scenario: Повреждённый инструмент
- **WHEN** publisher получает повреждённый archive, изменённый binary или неверную native version
- **THEN** он отклоняет новый artifact
- **AND** не перезаписывает исходные inputs

#### Scenario: Неуспешное обновление
- **GIVEN** ранее установленный kit
- **WHEN** новая поставка поиска повреждена или не проходит native probe
- **THEN** установка завершается с ошибкой, сохраняя прежний kit
