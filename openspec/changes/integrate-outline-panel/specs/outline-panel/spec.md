## Purpose

Показывает структуру текущего файла слева и позволяет пользоваться символами
и панелью с клавиатуры по общему маршруту Space w.

## ADDED Requirements

### Requirement: IDE-PANEL-3 Outline в общем управлении панелями

Редактор SHALL открывать/фокусировать Outline слева по Space w a и сохранять
Space l o / s o как переключатели, Space p o как раскладку. В одном left-слоте
SHALL быть один компонент: переход между Explorer и Outline закрывает прежний.
Outline SHALL показывать символы текущего файла из LSP с Treesitter fallback,
переключаться вслед за выбранным файлом и позволять j/k, Enter для перехода,
h/l для сворачивания/раскрытия дерева. Движение по списку MUST NOT само
переводить курсор в код до подтверждения. Общие q/Esc/?/Space w z/0/h/j/k/l
SHALL сохранять смысл пилота панелей: скрыть, вернуть zoom или фокус в код,
помощь, развернуть/вернуть, код, соседнее окно. Фокус SHALL быть виден в
заголовке. Ни открытие панели, ни файл без backend MUST NOT инициировать
установки инструментов или ошибок UI; отсутствие символов SHALL быть видимо.

Платформы: все
Проверка: tests/e2e/outline.test.lua (IDE-PANEL-3)

#### Scenario: символы и подтверждённый переход
- **GIVEN** открыт файл с настоящим backend символов
- **WHEN** пользователь открывает Outline, выбирает функцию j/k и нажимает Enter
- **THEN** код получает фокус на строке выбранной функции
- **AND** Outline остаётся слева; переход к другому файлу обновляет список

#### Scenario: общий маршрут и развёрнутый вид
- **WHEN** пользователь открывает помощь, закрывает её, разворачивает Outline
  и подтверждает выбранный символ либо возвращается Space w z
- **THEN** временные окна убраны, исходные окна и код сохранены
- **AND** Esc из обычной панели возвращает в код, q скрывает панель

#### Scenario: совместимость со слотами и отсутствие символов
- **WHEN** пользователь переключает Explorer и Outline старыми сочетаниями
- **THEN** виден один левый компонент и состояние менеджера соответствует окнам
- **AND** файл без backend/символов не показывает структуру предыдущего файла
- **AND** нет ошибок, запущенных установок или запущенной DAP-сессии

#### Scenario: повторное открытие дерева с отложенным follow
- **WHEN** пользователь быстро переключает Explorer/Outline и текущие файлы
- **THEN** отложенный follow дерева не обращается к удалённому окну/буферу
- **AND** нет ERROR или блокирующего ввода сообщения

#### Scenario: штатная команда backend
- **WHEN** Outline открыт командой AerialOpen без выбора раскладки
- **THEN** q по общему маршруту скрывает Outline и возвращает в код
