## MODIFIED Requirements

### Requirement: WT-PANE-7 Новое окно
Терминал SHALL по Ctrl+Shift+N (на macOS также по Cmd+N, WT-PANE-8) открывать новое окно WezTerm в текущем воркспейсе с одной вкладкой в домене текущей панели; размер и положение нового окна задаёт WT-STATE-2.
Платформы: все
История: FIXLOG 2026-08-01 «WezTerm: leader → липкий модальный режим WINDOWS», FIXLOG §32
Проверка: вручную на windows и macos (сценарий «Новое окно», результат — в записи FIXLOG)

#### Scenario: Новое окно
- **GIVEN** открыто окно WezTerm, активен воркспейс default
- **WHEN** пользователь нажимает Ctrl+Shift+N
- **THEN** открывается второе окно с шеллом по умолчанию в каталоге текущей панели (WT-PANE-12), в воркспейсе default
- **AND** окно стоит по центру активного экрана, его размер — сохранённый, а без сохранённого — доля экрана (WT-STATE-2)

#### Scenario: Русская раскладка
- **GIVEN** раскладка русская
- **WHEN** пользователь нажимает Ctrl+Shift+«т» (позиция N)
- **THEN** открывается новое окно

#### Scenario: Режим WINDOWS в новом окне
- **GIVEN** в первом окне включён режим WINDOWS
- **WHEN** пользователь нажимает Ctrl+Shift+N
- **THEN** в новом окне режима нет: он принадлежит окну (WT-WIN-1)
