# Панели: шпаргалка

`Space` — leader. Команды ниже работают в normal mode. Из terminal input:
`Ctrl-\`, затем `Ctrl-n` либо `Esc Esc`; `F7` сразу возвращает фокус в код.
В insert/terminal печатные символы получает редактор или запущенная программа.

Эксперимент с цельными рамками: `:ForgeFramePilot` в остановленном Debug,
повторная команда возвращает обычные окна. [Как включить и границы пилота](PANEL_FRAME_PILOT.md).

| Открыть / сфокусировать | Клавиши |
|---|---|
| Код | `Space w 0` / `F7` |
| Files / Outline | `Space w e` / `Space w a` |
| Git | `Space w g` |
| Locals / Debug Output | `Space w d` / `Space w c` |
| Tests / Test Output | `Space w t` / `Space w r` |
| Search / Tasks | `Space w f` / `Space w b` |
| Terminal | `Space w T` (заглавная T) |
| Problems / Trouble | `Space w x` |
| IDE Logs — общая консоль | `Space w i` / `:ForgeLogs` |

| Действие в рабочей панели | Клавиши |
|---|---|
| Соседнее видимое окно | `Space w h/j/k/l` |
| Следующее / предыдущее окно | `F6` / `Shift-F6` |
| Скрыть панель и вернуться в код | `q` / `Space w q` |
| Развернуть / вернуть | `Space w z` |
| Выйти из zoom, иначе фокус в код | `Esc` |
| Общая помощь | `?` / `Space w ?` |
| Закрыть помощь | `q` / `Esc` |
| Выбор / основное действие списка | `j/k` / `Enter` |

`[focus]` в заголовке показывает активную область. Открытие/фокус сохраняет
видимую панель; toggle отдельно скрывает/возвращает её. В коде `q` сохраняет
штатный смысл Vim, `Space w q` закрывает окно. Debug sidebar скрывается группой;
в Terminal/Trouble скрывается текущее окно. Скрытие сохраняет jobs и вывод,
не продолжает и не завершает отладку.

Помощь поверх zoom сохраняет развёрнутую панель плавающей; `q` возвращает
в неё, `Esc` из zoom — в исходный slot. Если backend закрыл исходное окно,
zoom убирается с возвратом в код. Явный выбор другой панели сохраняет её фокус.

В zoom название и `[focus]` находятся в цельной скруглённой рамке, без второй
строки заголовка внутри. Активная рамка использует DiagnosticInfo текущей
темы; при открытии `?` она становится приглушённой (Comment). Закрытие помощи
возвращает акцент. Оформление общее для панелей `Space w z`; постоянные
рамки обычных split пока остаются отдельным экспериментом.

Native UI образец: [активная рамка Locals](assets/panel-frames/zoom-locals-active.svg),
[та же рамка при открытой помощи](assets/panel-frames/zoom-locals-help.svg).
Windows E2E проверяет12 состояний рамок Locals/Output/Files/Logs и сохранение
настоящей DAP pause (§199). Для нового оформления Ubuntu/macOS и физическая
оценка WezTerm/шрифтов ещё не выполнены.

Terminal: `i` — ввод; normal `Ctrl-t` / `Space tt` — toggle, `Ctrl-\` из кода —
тот же toggle. В terminal-normal `Ctrl-\` остаётся native prefix; повтор
`Ctrl-\ Ctrl-n` безопасен. `Space w T` открывает/фокусирует без toggle.

Shell Terminal: на macOS/Linux используется выбранный при старте `vim.o.shell`,
даже если установлен `pwsh`. На Windows сохраняется `pwsh -NoLogo`, когда
Neovim видит executable `pwsh`; иначе используется `vim.o.shell`.
Глобальный shell редактора этот выбор не меняет.

## Читать уже напечатанный вывод

В живом терминале сначала `Esc Esc` (либо `Ctrl-\`, затем `Ctrl-n`): это
normal mode для просмотра буфера. Дальше работают обычные команды Neovim:

| Действие | Клавиши |
|---|---|
| Строка вверх / вниз | `k` / `j`, стрелки |
| Полстраницы вверх / вниз | `Ctrl-u` / `Ctrl-d` |
| Начало / конец накопленного вывода | `gg` / `G` |
| Найти текст | `/текст`, затем Enter |
| Следующее / предыдущее совпадение | `n` / `N` |
| Выделить текст / строки | `v` / `V` |
| Скопировать выделение / текущую строку | `y` / `yy` |
| Вернуться к вводу живого терминала | `i` |

Поиск/выделение/копирование доступны и в текстовых Debug Output/REPL/логах
в normal mode. Системный clipboard зависит от provider ОС; native yank Neovim
и доставка Cmd+C в WezTerm — отдельные механизмы. В read-only Output `i`
не превращает вывод в shell; для команд откройте Terminal (`Space w T`) либо
DAP REPL (`Space d R`). Для фокуса используйте Space w; Ctrl-b в нашей сборке
занят переключением левой панели, Ctrl-f — поиском в буфере.

Референс единой навигации — localvox-light: понятный фокус, движение по
списку, Enter/раскрытие, Esc к предыдущему контексту, подсказки действий.
Полный кейс — WF-13 в основном плане; новых привязок этим текстом не введено.

Trouble: `Space xx` — diagnostics, `Space xQ` — Quickfix; `zo/zc` — раскрыть/
свернуть, `Enter` — перейти, `g?` — штатная справка. В zoom новое выделение
используется подтверждённым действием backend. Files/Outline/Tests/Tasks/Git
имеют свою штатную справку `g?`; конкретные действия — в общей `?` и
[полном руководстве](../nvim_forge/QUICKSTART.md).

Git sequence editor: status `r i` → commit диапазона → Enter; `gk/gj` —
перестановка, `f` — fixup, `Ctrl-c Ctrl-c` — применить, `Ctrl-c Ctrl-k` —
отменить todo. Штатная отмена сохраняет HEAD/ветки/файлы. Настоящий конфликт
остаётся ошибкой; обычный rebase abort — status `r a`/Yes (§212).

Files `y/p`, `c`, `d` и защита несохранённых правок —
[краткий workflow](FILES_WORKFLOW.md).

IDE Logs: s — источник, f — текстовый фильтр, v — уровень, c — сброс,
r — обновить, Enter — детали, y — отчёт, H — :checkhealth forge.
[Источники, история и ограничения](IDE_LOGS.md).

Windows/Ubuntu: native E2E. Mac и физическая доставка клавиш WezTerm проверяются
отдельно; наличие одинаковой привязки не является результатом GUI-проверки.
