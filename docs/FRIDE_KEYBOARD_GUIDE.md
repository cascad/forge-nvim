# fride с клавиатуры

Сочетания с пробелами набирай по очереди. `Space w e` означает «пробел, потом `w`, потом `e`». `Shift+F6` нажимай одновременно. Заглавные буквы набирай с `Shift`. Если редактируешь текст, сначала нажми `Esc`.

## Комментарии и движение по строке на Mac

- В WezTerm с конфигом проекта нажми **Cmd+/** или **Ctrl+/** на клавише слева от правого Shift. Первое нажатие комментирует строку, второе снимает комментарий. В Visual действие применяется ко всем выделенным строкам. В Insert после нажатия можно продолжать печатать.
- В Normal нажми **Shift+6** для перехода к первому символу строки после отступа или **Shift+4** для перехода в конец. В Visual эти клавиши двигают конец выделения. Используй те же физические клавиши в английской и русской раскладках.
- В Insert и в строке поиска печатай знаки препинания в текущей раскладке как обычно.

## Перейти в панель и вернуться в код

- **`F6` / `Shift+F6`** — перейти в следующее / предыдущее открытое окно.
- **`Space w h/j/k/l`** — перейти в соседнее окно слева / снизу / сверху / справа.
- **`F7`** или `Space w 0` — вернуться в код.
- **`q`** или `Space w q` — скрыть рабочую панель, в которой находится курсор. Если панель нужна на экране, используй `F7`, чтобы продолжить работу в коде.
- **`Space w z`** — развернуть панель. Повтори сочетание, чтобы вернуть размер.
- **`?`** или `Space w ?` — открыть подсказку по текущей панели. `q` или `Esc` закрывает подсказку.

Прямые переходы также открывают панель, если она скрыта.

| Куда | Клавиши |
| --- | --- |
| Дерево файлов / список символов файла | `Space w e` / `Space w a` |
| Git | `Space w g` |
| Переменные (Locals) / вывод отладки | `Space w d` / `Space w c` |
| Тесты / вывод тестов | `Space w t` / `Space w r` |
| Поиск с заменой / задачи | `Space w f` / `Space w b` |
| Терминал | `Space w T` (заглавная `T`) |
| Диагностика | `Space w x` |
| Логи IDE | `Space w i` |

**Пример.** Открой Locals через `Space w d`, затем `Space w c`, чтобы посмотреть вывод отладки. `F7` вернёт курсор в файл. Если нижняя панель больше не нужна, войди в неё и нажми `q`.

## Открыть другой проект

1. Нажми **`Space o p`** или `Space f p`, чтобы увидеть недавние проекты.
2. Введи часть имени или пути. `Ctrl+J` / `Ctrl+K` двигают выделение по списку.
3. Нажми `Enter`, чтобы открыть выбранный проект, или `Esc`, чтобы закрыть список.

На стартовом экране список недавних проектов открывает `p`. В открытом проекте `Ctrl+P` ищет файлы.

Если папки ещё нет в списке, **`Space o f`** открывает ввод пути. Замени предложенный путь на нужный и нажми `Enter`. Если папка уже перед тобой в Files, поставь на неё курсор и нажми **`O`** (заглавную).

При переключении fride сначала сохраняет изменённые файлы. Если файл записать не удаётся, переключение отменяется. У другого проекта откроется его сохранённая сессия, если она есть. Переключение перезапускает редактор, поэтому работу в терминале и отладке лучше закончить заранее.

## Показать нужную папку в дереве

При запуске fride с путём к каталогу курсор сразу в Files. Из кода можно вернуться в дерево через `Space w e`.

| Что нужно | Что нажать |
| --- | --- |
| Посмотреть папки уровнем выше | `u`, `-` или `Backspace` |
| Сделать конкретную папку корнем дерева | Курсор на папку → `.` (точка) |
| Вернуть в дерево корень текущего проекта | `gR` (`g`, затем `Shift+R`). Из другого окна работает команда `:ForgeExplorerRoot` |
| Переключить весь проект на выбранную папку | Курсор на папку → `O` (заглавная) |
| Найти в дереве файл, который сейчас открыт в коде | В файле нажать `Space E` (заглавная `E`) |

**Пример.** Поднялся на уровень выше `lab`, чтобы посмотреть соседние папки. Чтобы снова показывать только `lab`, нажми `gR`. Чтобы временно видеть в дереве только `lab/src`, встань на `src` и нажми `.`. Поиск по проекту при этом по-прежнему идёт от `lab`. `Space E` раскроет путь к текущему файлу, сохранив другие раскрытые ветви.

В Files `j` / `k` двигают курсор, `l` или `Enter` раскрывает папку или открывает файл, `h` сворачивает папку. `H` переключает видимость скрытых элементов. `bb`, `bg`, `bf` переключают дерево между открытыми файлами, изменениями Git и файлами на диске. [Операции с файлами и папками](FILES_WORKFLOW.md)

В Normal нажми `Ctrl+W`, отпусти обе клавиши, затем нажми `>` или `<`, чтобы изменить ширину выбранной панели. Клавиши `+` и `-` меняют высоту. Для левой панели Files меняй ширину, для нижнего терминала выйди из режима ввода и меняй высоту. После `Ctrl+W` строчные `h/j/k/l` переводят фокус в соседнее окно, а заглавные `H/J/K/L` перемещают окно.

## Найти файл, команду или хоткей

| Что нужно | Клавиши |
| --- | --- |
| Найти файл по имени | `Ctrl+P` |
| Найти текст по проекту | `Space f g` |
| Перейти к уже открытому файлу по имени | `Alt+B` или `Space b b` |
| Листать открытые файлы | `Tab` / `Shift+Tab` |
| Закрыть текущий файл | `Cmd+W` на Mac, `F4` или `Space b d` на обеих платформах |
| Поставить или снять комментарий на строке или выделенных строках | `Cmd+/` на Mac, `Ctrl+/` на Windows |
| Найти команду | `Ctrl+Shift+P` |
| Найти хоткей по действию | `F1` или `Space s k` |

Чтобы открыть результат из Files или другой панели, нажми `Ctrl+P`, введи часть имени и подтверди строку через `Enter`. Файл откроется в окне кода. Если поиск запущен из кода, файл откроется в том же окне. `Esc` закрывает список и возвращает туда, откуда он был открыт.

**Пример.** Чтобы вспомнить клавишу для возврата к корню, открой Files, нажми `F1` и введи `root`. Так в списке будут доступны и клавиши, которые работают только в дереве. В поиске `Ctrl+J` / `Ctrl+K` выбирают строку, `Enter` подтверждает, `Esc` закрывает список.

## Запустить тест и разобрать падение

1. Открой файл с тестами и нажми `Space w t`. В панели Tests выбери строку конкретного теста через `j/k`.
2. Нажми `r` (русская `к`). Запуск на строке самого теста проверяет его, запуск на строке файла проверяет тесты этого файла.
3. Дождись результата рядом с тестом. Нажми `o` (русская `щ`) на его строке, чтобы открыть вывод, включая причину падения или пропуска, если тест её записал. Если вывода ещё нет, появится короткое сообщение. `Esc` или `q` (русская `й`) закрывает окно вывода и возвращает к выбранному тесту. `Space w r` открывает общую панель вывода.
4. Нажми `i` в Tests, чтобы перейти прямо к тесту в редакторе. Внеси правку, сохрани файл и нажми `Space T t` с курсором внутри теста для повторного запуска. Первая `T` заглавная.

Если нужен отладчик, нажми `d` на строке теста в Tests. Для веток `l` раскрывает, `h` сворачивает, `Enter` переключает состояние.

Чтобы скрыть Tests или Test Output, переведи фокус в соответствующую панель и нажми `q`. Клавиша `u` на строке выполняющегося теста останавливает его.

## Терминал и логи

- **Ввести команду в терминале.** `Space w T` открывает или фокусирует терминал. Если ты в режиме просмотра, нажми `i`, чтобы начать вводить команды.
- **Выбрать PowerShell, Bash или другую оболочку.** Нажми `Space t S` (заглавная `S`) или введи `:ForgeTerminalShell`. Выбери `Auto`, найденный бинарь или «Указать путь к бинарю…». Например, можно указать путь к отдельной установке `pwsh.exe`. Нажми `Space t N` (заглавная `N`), чтобы открыть новую консоль с выбранной оболочкой. Старую консоль можно снова выбрать через `:TermSelect`.
- **Прочитать уже напечатанный вывод.** Нажми `Esc Esc` или `Ctrl+\`, затем `Ctrl+N`. Теперь `k` / `j` листают строки, `Ctrl+U` / `Ctrl+D` — полстраницы, `gg` / `G` — начало / конец вывода. Чтобы скрыть терминал, нажми `q`. Чтобы сразу вернуться в код, нажми `F7`.
- **Отправить фрагмент из файла в терминал.** Выдели его через `v` или `V`, затем нажми `Space t e` или `Ctrl+Enter`.
- **Понять, почему что-то не запустилось.** Нажми `Space w i` или введи `:ForgeLogs`. В логе `s` выбирает источник, `f` ищет текст, `v` меняет уровень сообщений, `Enter` открывает детали, `r` обновляет. `G` возвращает к последним сообщениям, `gg` — к началу. Если нужно выбрать или подготовить языковой инструмент, открой `Space l S`.
- **Посмотреть ошибку при запуске редактора.** Введи `:messages`. Эта команда Neovim доступна и при сбое загрузки конфига.
- **Посмотреть ошибки и предупреждения в коде.** Нажми `Space w x` для списка диагностики. На строке с подчёркиванием `gl` открывает текст диагностики.
