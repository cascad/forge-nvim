# Хоткеи по фактической приёмке владельца

Обновлено: 2026-11-22. Это накопительный список для будущей личной шпаргалки.
Источник — сообщения владельца. Автотесты, выданный чек-лист и выбор нового
сочетания не считаются ручной приёмкой. После исправления прежний отказ остаётся
«перепроверить», пока владелец не подтвердит результат.

`Space` — leader. Если режим не указан, сочетание используется в normal mode.

## Точно использовал или сообщил результат именно по сочетанию

| Клавиши / среда | Назначение | Что подтверждено владельцем |
|---|---|---|
| `gR`, Files, EN | Вернуть корень дерева к рабочему проекту | **Работает**: «gR — работает только в англ раскладке» |
| Физические `g`, `Shift+R`, Files, RU (`пК`) | То же на русской раскладке | **Был отказ**. Исправление a7cf782 установлено; повтор владельцем ещё нужен |
| `Ctrl+Shift+P` | Открыть палитру команд | **Использовал**; сообщил дефект отступов при навигации. После исправления ручной PASS не сообщён |
| `Ctrl+J` / `Ctrl+K`, палитра | Следующий / предыдущий пункт | **Использовал**; строки сдвигались вправо при каждом проходе. После исправления перепроверить |
| `j`, Files | Перемещение по дереву (текущее назначение — вниз) | **Упоминал использование**. Сообщённый подъём выше проекта нельзя уверенно приписать j: точная клавиша подъёма не подтверждена |
| `F5`, Windows, Python | Запуск/продолжение отладки | **Использовал**; были ошибки запуска debugpy. Позже сообщил, что одностраничные Python/Go/Rust скрипты запускаются нормально; точные keys для последнего прогона не названы |
| `Cmd+C`, macOS/WezTerm | Копирование | **Сообщал отказ**; подтверждения повторной приёмки на Mac нет |

## Действие проверялось, точная клавиша не названа

Здесь указаны штатные сочетания сборки для этих действий. Их нельзя помечать
как уже нажатые владельцем: сообщение подтверждает действие, а не способ вызова.

| Действие | Штатные keys для будущей шпаргалки | Результат ручной проверки |
|---|---|---|
| Создание файла с кириллицей | `a` в Files | Файл создавался, повтор давал file exists; первоначально отсутствовал в дереве |
| Копирование файла | `y` → выбрать папку → `p` | Файл появлялся на диске, но временно не был виден в целевой папке |
| Перемещение файла | `x` → выбрать папку → `p` | Перемещение проверялось; source оставался с красным крестом, destination временно не виден |
| Удаление пустого каталога | `d` в Files | Было длительное зависание/потеря управления, затем операция завершилась с задержкой |
| Найти и открыть файл | `Ctrl+P` | Поиск и открытие использовались; затем запрошен reveal выбранного файла в дереве |
| Подняться выше корня проекта | `u` / `-` / Backspace в Files | Сам подъём подтверждён; каким сочетанием выполнен — не установлено |
| Открыть Help | Точный вызов неизвестен | Help появилось случайно при попытках выйти из сбоя и восстановилось после перезапуска |

Для create/copy/move/delete были исправления и автотесты. Окончательного ручного
подтверждения исходных сценариев после обновления пока нет.

## Как дополнять

- «Нажал / пользовался» — пометить использование, не выдавать за успешную приёмку.
- «Работает / проверил нормально» — записать ручной PASS вместе с ОС и контекстом.
- При отказе сохранить симптом и версию исправления; закрыть только после повтора владельцем.
- Если проверялось действие без названной клавиши, не угадывать способ вызова.
