# IDE Logs: native Mac и physical WezTerm

Пока не проверено. Headless/RPC/embedded TUI не подтверждают доставку физических
клавиш и системный clipboard. Использовать текущую сборку и подготовленные tools;
Windows/Ubuntu автоматические результаты записываются отдельно.

1. Записать ОС, Neovim/WezTerm версии, layout и путь загруженного конфига.
2. Space w i/:ForgeLogs: сообщения, s источник, f текст/отмена Esc,
   v уровень, c сброс, / поиск, Enter детали, r обновление.
3. ?/q помощь, Space w z resize/restore, Space w h/j/k/l/0 и q/reopen.
   Проверить английскую и русскую раскладки и обычный терминал без WezTerm.
4. Вызвать настоящий missing tool через штатный Debug/Format; найти причину
   и действие в консоли, подготовить tool явно и повторить действие без restart.
5. Выбрать существующие LSP/DAP/format/tests/Git/tasks logs и Output.
   Отсутствующий/пустой/отключённый источник должен быть помечен.
6. y: вставить отчёт в другой программе через системный clipboard; проверить
   Unicode/переносы строк. Вставка в код не должна выполняться автоматически.
7. Закрыть редактор, открыть вновь: найти сообщение прошлой сессии и её ID.
   Проверить H/:checkhealth forge; просмотр не должен устанавливать tools.
8. Failed F5 → немедленно Space w i/x: поздний Debug focus не забирает панель.
   У работающего Debug/terminal смена фокуса не продолжает/останавливает процесс.

Проверено: <дата>, <ОС>, Neovim <версия>, WezTerm <версия>, layout <…>,
config <…> — совпало | расходится: <шаг/симптом/артефакт>.
